# 原作怎样把意思写进字句

用于表达型润色的选句校准。以下短摘来自已保存的自动转写，未逐字人工校对；选取了语义清楚的部分。语境为转述，**平译与失效示例均为整理者自拟**，分析不是老师公布的体系。比较的是表达产生的作用，不照抄措辞，不把示例中的经历、性能或立场移给用户。

## 1. 一个动词让状态可见

**语境：**作者讲一张用了多年的旧办公椅。

**原作：**“海绵顺着缝线炸开。”

**平译：**椅子破了，里面的海绵露出来了。

**多了什么：**“顺着缝线”给出破损路径，“炸开”写出向外绽出的形态。物件自己显出衰败，不必宣布“非常破旧”。这是准确观察带来的力度。

**失效仿写：**“岁月把椅子炸成生活的废墟。”声音变大，实际形态反而消失。没有相应细节时，不能靠强动词造事实。

来源：[S31 原作](https://www.douyin.com/video/7306797205535378738)，6.01–10.13秒；研究稿 `research/asr/7306797205535378738.md`。

## 2. 让两种关系共用一个说法

**语境：**作者自己讲吃米饭的感受，前文已有软硬适中的口感。

**原作：**“上牙和下牙因为这软硬适中的口感缓和了关系。”

**平译：**米饭软硬合适，嚼起来舒服。

**多了什么：**牙齿接触的身体感受，借到人与人相处的语境。“缓和”同时承担舒适和幽默，联想从咀嚼本身长出来。

**失效仿写：**“米饭与灵魂达成和解。”缺少可感的对应，换成许多食物都成立，只剩姿态。

来源：[S11 原作](https://www.douyin.com/video/7147206060955176205)，23.57–35.26秒；研究稿 `research/asr/7147206060955176205.md`。

## 3. 有抱负，也保留说话人的分寸

**语境：**整段用灯泡讨论文案，作者随后谈自己未来想做什么。

**原作：**“未来十年，我争取当你的文案明灯。”

**平译：**我希望以后能帮助你学习文案。

**多了什么：**“明灯”接住刚谈过的对象，照明转成引导；“争取”让愿望仍是愿望。亲近与抱负来自同一句话，不靠自封权威。

**失效仿写：**“我就是照亮所有人的唯一灯塔。”比喻更大，却丢了原有范围、意向和口气。

来源：[S22 原作](https://www.douyin.com/video/7200296776337837373)，176.86–185.80秒；研究稿 `research/asr/7200296776337837373.md`。

## 4. 锋芒落在判断的区别上

**语境：**作者讲自己没有沿着委托方的营养措辞继续包装，而是重新考虑沟通问题；这是他对此事的主张。

**原作：**“顺从的文案修饰问题，不听话的文案解决问题。”

**平译：**写作者需要判断任务，而不只按要求美化说法。

**多了什么：**“修饰／解决”清楚地区分两种处理方式，“不听话”承接他冒险提出不同意见的姿态。工整为判断服务。

**失效仿写：**“听话的都是废话，不听话的才有价值。”靠扩大断言制造狠劲，把具体主张偷换成普遍定律。原作的修辞判断也不能直接当通用事实。

来源：[S05 原作](https://www.douyin.com/video/7161333307500711176)，94.14–111.18、140.23–149.56秒；研究稿 `research/asr/7161333307500711176.md`。

## 5. 普通词也能写出对人的态度

**语境：**片中将包装化的奶源描述改成日常说法。

**原作：**“使劲挑选奶源，用力让你放心。”

**平译：**我们认真选择奶源，希望消费者放心。

**多了什么：**体力词进入选择与关照的语境，人的投入从商家这一端抵达读者。朴素词语仍有意外搭配和清楚对象。

**失效仿写：**“拼命做到最好，让全世界放心。”对象与实际工作都消失了，还添了程度和范围承诺。

来源：[S23 原作](https://www.douyin.com/video/7216255203232746813)，177.47–191.60秒；研究稿 `research/asr/7216255203232746813.md`。

## 6. 有些意思，平实说准就够了

**语境：**片中讨论纯棉材料，反对把普通材料包装成夸大的技术优势。

**原作：**“没有什么核心科技，只是我们坚持纯棉。”

**平译：**我们一直采用纯棉材料。

**多了什么：**“只是”收回自夸，“坚持”交代选择的态度。没有另添意象，也能听出一个人的自知。这里只借其说话分寸，不据此判定现实产品有无技术。

**失效仿写：**“让每一根棉纤维守护岁月的初心。”具体选择被通用赞美遮住，修辞没有增加理解。

来源：[S37 原作](https://www.douyin.com/video/7259670737206775052)，116.41–145.56秒；研究稿 `research/asr/7259670737206775052.md`。

## 把标尺带回当前稿件

读完再看自己的候选：哪个词让读者看见了更准确的动作、感到更贴切的关系，或听出更清楚的态度？去掉修改说明，收益仍应在正文里成立。能给微小调整解释一个理由，不等于关键意思已经写好；反过来，原有好句不必为了展示技巧而重写。

这些例子不规定修辞密度。比较候选时，既保留材料独有的意思，也比较它们是否比平译多了值得保留的理解与感受；只有响亮、工整或新奇的句子，不能因此胜出。
