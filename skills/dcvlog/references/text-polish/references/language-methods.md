# 字句生成方法卡

M01—M12是整理者的操作分类，不是老师命名的十二招。每张卡解决一种生成问题；使用时先读匹配的[改写示例](generation-workbench.md)，看到从原意到新表达的实际转换。S编号对应[49条来源](source-index.md)。原片主张、实际语言观察与我们设计的通用操作需分清。

## M01 用动词把状态写出来

**依据：**S30明确反对用笼统形容掩盖感受；S31开场写旧椅子，以具体磨损的动作呈现状态；S23用日常动作替换包装词。

**怎样生成：**

1. 从材料中找“什么在怎样变化”，先写出最普通的动词，辨认方向、力度、持续或姿态。
2. 在相同动作范围内找更有承担力的词。移动可以轻、急、卡住或反复；具体选择取决于已知状态，不取决于哪个词显得大。
3. 必要时让事物成为动作主语，或让抽象状态借一个可理解的物理动作显现。选一个动作，让其余字词给它让路。

**收益：**读者看见状态，也可能从动作感到作者的态度。新动词必须解释得通，不能把小幅变化改成严重破坏。普通而准确的词往往比激烈的词更好。

## M02 让预期与态度进入小词

**依据：**S35明确讲情绪词；S02、S37的自知与回应、S48的程度措辞是实际说话姿态的证据。

**怎样生成：**

1. 辨认原稿“本来以为怎样，实际怎样”，或“我在意什么、保留什么判断”。没有预期差，就另选路径。
2. 试着把态度落在一个词或语序上：才、还、倒、也、竟然、算是，各自携带不同的预期。替换后读一遍，体会作者是惊讶、无奈、自嘲还是松了一口气。
3. 删掉为同一种态度重复服务的情绪标签。需要时保留作者自然的停顿、补一句或自我纠正。

**收益：**事实之外能听见说话人；不靠每句喊“太、真的、绝了”。语气词不能凭空增加惊喜、后悔或不满。

## M03 把感觉接到熟悉的身体经验

**依据：**S03明确用熟悉记忆传递气味；S11的口感拟人、S15的触感类比、S41的生活联系提供不同做法。

**怎样生成：**

1. 拆开抽象感觉：它是黏住、压着、松开、扎一下、缓慢铺开，还是其他可感的性质？
2. 在常见身体经验里找同性质的载体。比较的是一项感觉，不必复制整个情境；原稿没有出现该载体，也可以借它作明确的比喻。
3. 用一个具体动作或质感把两者接起来，必要时用“像”标清。已有真实细节时，也可以直接让细节发声。

**收益：**读者能感到差别，而非只接收“舒服、治愈”等评价。借衣服的束缚感解释沉闷是表达；声称作者当天穿了某件衣服是新事件。二者不可混淆。

## M04 先找关系，再找喻体

**依据：**S01的穿着失配、S15的类比、S39的匹配关系、S49的尺码说明。S39明确讲方法；其余也含作者实际解释问题的写法。

**怎样生成：**

1. 把本义压成一项关系，如局部与全貌、投入与回应、容量与负荷、连接与阻隔。不要先搜“好听的比喻”。
2. 为同一关系找两个熟悉载体，比较哪个最少解释就能成立。喻体可以新，但它只能解释原来存在的关系。
3. 建立对应：谁对应谁，哪个动作对应什么。保留最有用的一项，删掉不对应的附带功能。
4. 用一句自然话让映射发生。明喻、暗喻、拟人都可；本义难辨时改用明喻或直说。

**收益：**抽象意思获得可见的动作和距离。不是把漂亮物件贴在句子上，也不把功能有限的对象比成能完成一切的对象。

## M05 让熟悉词在两个语境中通电

**依据：**S24、S25、S29的实际用词呈现物性与人情、工作与生活之间的两义；S06、S34明确讨论意外搭配；S21展示熟悉表达的有限变换。

**怎样生成：**

1. 列出当前对象最自然的动作或属性，再找这些词在人或另一对象上的常用意义。优先从对象本身找词。
2. 确认两边都自然：同一动词可以连接不同宾语；同一形容词可以在物理与情绪层面成立。若其中一边必须硬解释，换词。
3. 保留原句里能认出的部分，只更换关键对象、程度或语义角度。两义可以在相邻短句里照应，也可藏在一句话中。
4. 检查意外之后是否仍能立刻读懂。词义反差要帮助表达真实的关系或态度。

**收益：**普通词多出第二层意思，产生机趣、余味或记忆点。负面词进入赞美语境时，要有行为作解释；把缺陷改名，不算完成。

## M06 给意思换一个可感的计量方式

**依据：**S09明确讲数字尺度；S31讲参照，并在实际文案中让抽象感受与具体量词相遇；S40用投入和区别说明分量。

**怎样生成：**

1. 找出相对评价的参照：对谁、与什么相比、在哪个条件下成立。
2. 事实性数量可转换成准确的行动成本或人能理解的单位，条件不齐就不换算。
3. 情感性表达可以用具体事物承载感受的分量，如一个物件联系一段已经表达的等待、安稳或牵挂。这里是修辞计量，不伪装成新统计。
4. 比较“更大更多”的程度升级，与“具体换来了什么”的关系变化，优先选更能说明这件事的那个。

**收益：**让人理解值在哪里、重在哪里；不只叠加程度词。主观价值保留归属，不偷换客观价格或效果。

## M07 把抽象好处写成能发生的一件事

**依据：**S10明确把抽象价值写成具体风险动作；S33、S36、S45从具体愿望或处境解释意义。源剧情与营销数字不作为真实事实。

**怎样生成：**

1. 找材料已支持的变化：谁现在能做什么，少受哪种阻碍，或在哪个具体时刻得到什么帮助。
2. 把系统、产品或抽象概念退到必要位置，让人的动作和实际变化成为句子焦点。
3. 用那个变化替代“贴心、提升、便利”等空泛判断。可以通过省略、轻微转义或说话语气，使它成为自然的一句。

**收益：**把一个泛泛的好处变成人能理解的用途。不能为了有场景就给读者编痛苦、给功能添本领。

## M08 让真实限度成为说话姿态

**依据：**S12、S27明确谈不完美；S37、S48强调自知与有限评价；S46展示负面词在真实行为中的重新解释。

**怎样生成：**

1. 辨认原稿真实的取舍：做到了哪一项，做不到或不追求哪一项。限度可能是特色，不能自行制造。
2. 用能显示自知的动作、轻微保留或自嘲代替自我授奖。若原作者已有笃定，则用有依据的事实支撑，不自动削弱。
3. 让“知道自己在做什么”的态度出现。坦率可以有锋芒，谦虚不必成为统一语气。

**收益：**可信感与人物感一起出现。为显得真实故意发明短处，或用小短处遮住真实问题，都不成立。

## M09 用说话动作写出人的关系

**依据：**S23讲日常词；S26承认正式与野性语域；S29、S43、S44讨论关系姿态；S42里礼貌动词与尖锐态度形成反差，是实际语言观察。

**怎样生成：**

1. 认出作者正在做的说话动作：感谢、承认、辩解、提醒、自问、调侃或拒绝。不要只识别“正面/负面情绪”。
2. 按真实关系，试一种更准确的称呼、主宾位置、口头补充或回应方式。让态度发生在句子里，少用“我很真诚/我很无奈”自我说明。
3. 可让礼貌与尖锐、笃定与自知同处一句，但两层态度必须是原稿允许的。普通动作词也能写出锋芒。
4. 读出声，检查是否像这个人面对这个对象会说的话。

**收益：**活人感来自具体选择与关系分寸，不取决于语气词数量。不要把有性格的作者磨成统一温柔腔，也不把普通人改成老师本人。

## M10 让句子的节奏跟着意思走

**依据：**S38讲凝练；S05、S26、S48的局部复现与短句是文本观察；S30提供“具体句可以更长”的反例。

**怎样生成：**

1. 找句中承重的名词、动词和转折，删掉重复包裹它们的抽象名词与解释。
2. 比较一口气说完与在语义完成处停一下的差别；把真正承重的词放在能被听见的位置。
3. 如原意有递进或并列，尝试保留一个共同词、改变其余部分，让读者听到差别。长度变化应服务意思。
4. 留下必要指代与条件。朗读时，节奏不应逼着读者重新拼逻辑。

若一组长句反复解释同一个意思，可以先提炼它的核心关系，再结合M11、M04或M05，让一个短句承载原来分开说明的判断与感受；不只是把长句拆成几段。能在当前上下文中读回的重要意思才可省略显说，独立事实和逻辑台阶不能被一句漂亮话吞掉。

**收益：**句子更有力度、呼吸与回响。简洁不是固定字数，不把每段切成广告式断行。

## M11 把判断压进一个词语关系

**依据：**S05用动词区别两种行为；S07、S21、S25把声音、熟句或两义用于判断；S19、S26的句内呼应让差别易于记住。

**怎样生成：**

1. 用不漂亮的白话说清原稿发现了什么，保留它的适用范围。这一步还没有判断，就先别造金句。
2. 找判断两端之间真正的联系：动作与结果不一致、期待与实际有落差、同一对象被不同方式对待等。也可以只有一个准确观察，不必强造两端。
3. 试找一个共同动词、名词或句式载体，让差别在更少的字里出现；再试一个完全不对仗的版本，比较哪个更自然。
4. 删掉句子后面重复解释它的字。保留“我、这次、可能、常常”等承载归属或分寸的词。

短句的余味可以留给读者会意：字面先成立，第二层意思由原稿已有的关系与上下文支撑。不必把已经被表达的意味再解释一遍，也不为制造深刻而藏掉必要信息。

**收益：**读者记住的是一个发现，不是空口号。短句可以尖锐，也可以有保留；不可为工整补出原稿没有的普遍真理。

## M12 改变大与小、远与近的观看距离

**依据：**S49明确谈尺度错位；S41把物件与具体生活联系；S48与S28分别提供避免强加传奇和虚假包装的边界。

**怎样生成：**

1. 找对象的通常尺度，以及原稿已经建立的另一种尺度：物件很小但联系重要，概念很大但在一个普通动作里体现。
2. 把两种尺度接在同一句里，优先使用一项具体动作或用处，不搬来一整段宏大故事。
3. 让读者能从小处走到那层已有意义，或从抽象高处落到可理解的地方。连接存在即可，不必用“这就是人生”解释。
4. 若换成任何普通物件都能成立，多半是套话；回到这件事独有的关系。

**收益：**既有意思获得意外的分量或亲近感。借新意象表达原有联系是允许的，发明传奇来抬高对象则越界。
