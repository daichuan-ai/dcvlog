# 来源索引：S01—S49

来源为抖音账号“叫我舒老师”的“文字科学”合集，编号沿用本项目目录中的集序。标题保留原题主体，省略话题标签；链接指向原作品。时间均为原视频起点后的秒数，不是剪辑时间线位置。

**证据层级：**“老师明说”表示原片明确提出的语言主张；“我们的字句观察”表示整理者从其实际用词、句法和修辞中归纳的现象，不冒称老师原生方法名。M01—M12 是[字句润色方法卡](language-methods.md)的工作分类；对应关系表示有相关语言证据，不表示整条视频都可照搬。

**核验范围：**49 条来源均已有时间戳转写并完成文字阅读；转写来自自动语音识别，未逐字人工校对，部分方言、专名、歌词及画面主导内容存在缺失或疑字。以下主要是转述，不是逐字引文。来源中出现的经营数字、收益、销量、理论名词、心理学归属与健康推论不作效果实证。可执行的只有有条件的语言操作，不能用假事实、假记忆或假人物心理增强文采。S28 的讽刺演示与 S32 的错误推论单独隔离为边界材料。
