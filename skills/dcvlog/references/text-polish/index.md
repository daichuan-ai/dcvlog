# 文字科学：字句的表达力

用户已经有一份完整文案。先理解其中每一处想表达的意思，再借合适的方法把它说得更准确、可感、凝练或有余味。学习词语怎样产生作用：动作的准确、搭配的意外、隐喻的对应与态度的分寸。编辑单位是词、句和相邻的一组句子；通读全文是为了理解上下文、让修改接得上，不要求重写全文。

源于49条公开作品，既研究老师明说的方法，也研究他自己的实际写法。这里的机制、操作与自拟例子由整理者归纳，不是作者的官方体系，也不要求模仿他的口头禅。出处与整体特点保存在参考库，普通润色无需读取溯源目录。

## 先辨认任务的力度

- 只纠错、只改标点、指定保留措辞：遵守该范围。
- 精确通知、操作说明、已成熟的文字：优先使必要信息好懂，按实际需要调整。
- 润色、增强表达、炼句、想更有意味或记忆点：进入下面的表达生成过程。默认允许在原意内重新选词造句，不需要再询问是否允许使用修辞。可以只换一个准确的词，也可以重铸相邻几句；判断依据是表达收益，不是改动数量。

起稿前，将必须保留的数字、量词及其对应对象，连同否定、条件、可能性，暂记为完整的事实短语。锁定人物关系、责任和作者真正的判断与情绪。保留这些，不等于保留原句的表面说法。默认沿用内容次序与段落任务；可以重铸句子、调整句内重心和相邻短句的呼应，不主动设计开头钩子、故事推进或结尾升华。

## 从原意生成表达

先通读用户原稿，再用下面的路径表选择当前最有用的表达手段。参考库用于解决选中的问题，不是每次开工前的必读书单：

- 按表中的编号，定位并读取[方法卡](references/language-methods.md)对应的小节，以及[改写示例](references/generation-workbench.md)标题标有相应M编号的示范；先取最贴切的一两组，遇到新的具体表达问题再补读。
- 需要校准表达分寸时，从[原作校准](references/source-calibration.md)选相关一例：动作看第1例，联想看第2例，态度看第3或第6例，判断看第4例，普通词的搭配看第5例。
- 支持搜索或局部读取的宿主，按小节标题定位；不支持时读当前需要的文件即可。无需为润色把所有参考读完。

本文件下述生成、比较和验收是实际工作流程；方法卡与示例负责提供当前这一步用得上的做法。

**1. 找到有东西可写的关系。** 用直白话认出这一处的对象、动作或感受，以及值得说的差别。例如：两件事同时成立却不协调；一个小动作承载了某种态度；一件东西的用途与人的愿望发生联系。先认出原稿里已有的关系，不急着寻找漂亮词。

**2. 为有表达空间的局部试写。** 从第1步理解到的意思出发，寻找适合这一处的方法。有必要时暂时放开原句词序，尝试不同方向的表达，再与原句比较；不要求每处生成固定数量的候选。重新组织的是字句，材料、立场和事实短语仍来自原稿。

| 需要的表现力 | 试写动作 | 方法卡 |
| --- | --- | --- |
| 让状态、感受可见 | 找支撑意思的细节，选出携带方向、力度或姿态的动作词 | M01、M03 |
| 普通词产生第二层意思 | 找一个两边都能自然使用的词，改变它的搭配对象或语境 | M05 |
| 抽象意思可感知 | 提取一项关系，再借一个共享该关系的具体事物来表达 | M04、M12 |
| 句子有态度、像本人 | 找作者的期待、取舍或自知，让小词、称呼、主宾位置承载它 | M02、M08、M09 |
| 说出好处或代价的分量 | 选择恰当参照、动作或具体得失，把变化说到人能理解的尺度 | M06、M07 |
| 一组长句绕着一个意思解释，或希望留下一句有余味的话 | 提炼核心关系，让一个动词、双义词、对照或贴切意象承载原来分开解释的意思 | M10、M11，按需结合M04、M05 |

这张表是选择路径，不是每篇都要完成的技巧清单。找到合适方法时认真发挥，不停在轮换几个形容词；没有贴切方法，或试写不比原句好，就保留原句。生成的是备选字句，不必给用户多版全文。选中一处有力的表达后，周围可以平实，给它留出空间。

### 把长句炼成短句

相邻几句如果都在解释同一个感受或判断，可以把这一组当成一个表达单位，提炼它真正想说的关系，再试一句更紧凑的话。除了删冗词，还可让一个准确动词、双义词、对照或贴切意象，同时承担原来分开解释的几层意思。先看改写示例13的完整凝练示范，再按实际关系选M10、M11或示例02、05、11、12，不套统一句式。

允许把话留半步，让读者从当前上下文读出暗示或第二层意思。余味应来自原稿已有的关系，听懂字面后能自然会意；不能靠晦涩、凭空拔高或必须另讲一段的谜语制造深刻。用于短视频口播时，还要一遍听懂、读得顺口。

压短后，将新句放回原处，核对原来重要的意思是否仍由它或相邻句子承载。被新句已经表达清楚的重复解释可以删；独立事实、必要条件和逻辑台阶要留。多件独立的事无法合进一句时，不强压，也不把全文切成金句。目标是提高一句话承载的意思，不是达到某个字数。

**3. 比较哪句多提供了理解与感受。** 具体指出候选的收益：一个动词让状态可见；一个双关使两层意思照面；一个比喻说明关系；一种句内节奏把真实判断留住。新鲜感必须能被读者顺着意思解开。若只能说“更高级、更文艺”，还没有找到理由。

原句也是候选。比较新旧说法时，看它有没有更准确地写出原文已有的动作、关系或态度。若只是增加一个比喻、补一句议论，或把作者独有的细节换成通用感悟，保留原句。选中一句有力的新表达后，删去随后重复解释它的句子，让周围平实地承接。改多少由原稿决定。

**4. 按合适的强度交稿。** 从有收益的候选中选自然、准确、符合作者的一版。无需让每句都有修辞，不把所有文字都改得柔软、燃、俏皮或广告化。作者本来尖锐、幽默、犹疑或笃定，就沿着那种声音工作。

## 新表达与新事实要分清

可以新造喻体、拟人、动作化表达、词义联系和句内节奏；借来的物件不必在作者的生活里真实出现。判断关键是读者是否明白它在解释什么，而非把它当作新发生的事情。

例如，“争论总回到起点”可以借原地转圈说明；不能改成“我们昨晚争了三小时”，因为这增加了事件与时长。原稿只有孤独，不给作者编一段童年；原稿已有孤独，可以创造贴切的表达来写它。效果、数字、承诺和他人的内心仍须有依据。

原稿明确的幽默夸张不必一律降成客观说明。修辞可以放大感受，但不得悄悄改变作者对谁负责、承诺做什么，或把可理解的玩笑写成真实指控。

## 两种验收都要做

**含义验收：**用普通话还原改写，是否仍是作者原来的事实、判断、意向与情绪？逐项对照起稿前的事实短语：量落在同一对象上，否定作用于同一行为，条件、程度和因果未改变。再查新加的关键动词：它表达的是原来的行为，还是换了一种行为？有变化就局部退回原义，不为保住漂亮句子解释辩护。

**表达验收：**逐处比较拟采用的改动与原句，收益是否在正文中成立？修辞贴切，短句有内容，联想能被解开，口气像作者。若只是多了装饰、把细节换成通用感悟，或需要修改说明替它辩护，就不采用。原句已经合适也是有效结果，不按篇幅规定改动比例或金句数量，不为交差强改。

最后将改动放回全文，检查指代、衔接、重复与作者声音。这是上下文检查，不是要求更多段落发生变化。

读出声：是否顺着人的理解而走，是否像作者在这个场合会说的话？删除必须解释半天的机巧；保留有意味的简单话。具体的长句也可能比空泛的短句更有力。

默认交付一版完整可用稿；只选定局部时交付该局部。用户需要说明时，给少量原句与改句并解释实际收益，不输出内部候选或完整分析过程。用户明确要多版时再提供。无需自行扩展标题、分镜、配图和发布建议，也不必在每次润色中提老师姓名或方法编号。
