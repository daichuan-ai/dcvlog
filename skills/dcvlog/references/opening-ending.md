# 前5秒 + 结尾｜主角型开场、客人直入、现场原声、人设尾巴

## 一、前5秒一定后置

主体采访完成后再做。先说：

> 好，正文已经有了。最后只看前几秒怎么开。我给你四个方向，你直接选数字就行。

固定四类，不能新增第五类：

**1. 强画面｜化妆师主角型Vlog开头**  
工作室漂亮、远景/中景/特写完整，或者你本人有高审美自拍、穿搭、工作状态、动作等能先建立“这个化妆师是谁”的画面。

**2. 强情绪｜真实现场原声**  
客人真实笑声、尖叫、惊讶、情绪明显的对话或互动。

**3. 强数字｜有证据的数字**  
付款、尾款、充值、客人数等当天确实有截图、页面、录屏或现场画面。

**4. 纯文案钩子｜直接从客人进入**  
没有主角型强画面时，从客人坐下/脸部画面开始，第一句直接讲她今天要干什么、想要什么、有什么麻烦或最值得看的变化。

> 你今天更接近哪一个？直接回数字就行，几个都有也可以说。

命中明确方向后，不继续追问一长串。最多给2个成品开场让用户确认。

---

## 二、方向1｜强画面不是“随便一个漂亮镜头”，而是化妆师主角型开场

只有出现下面这类素材，才优先走1：

- 漂亮/有辨识度的工作室远景、中景、特写；
- 化妆师本人高审美自拍、出镜、穿搭、妆面、动作；
- 能让观众先认识“这个化妆师/这家工作室”的工作状态；
- 画面本身足够撑住前2—4秒。

命中后，旁白不是描述画面，而是用前面已经确认的资料快速建立主角身份。优先组合：

`代际/年龄 + 城市 + 工作/创业状态 + 最有记忆点的真实特点/目标 + 一天Vlog`

例如逻辑：

> 00后化妆师，在绵阳开个人工作室，专门给普通女生找最适合自己的妆，今天继续营业。

这只是机制示意。城市、年龄、业务、特点必须来自用户真实信息。

### 方向1后面的标准进入顺序

`工作室/本人强画面 → 客人开门到店 → 介绍今天客人 → 沟通画面 → 提出客人的用途/真实需求/问题/变化`

不要一上来就剧透最终妆后结果。

### 强表达规则

开场要有记忆点，减少“可能、大概、有一些、有一点、比较、稍微”。在真实方向允许时，优先：

`超 / 超级 / 最 / 特别 / 很 / 最会 / 最懂 / 最稳 / 最细 / 最负责 / 厉害`

但“表达要强，事实要真”。不得无依据写“全城第一、行业唯一、最厉害”等可核验事实。

---

## 三、方向2｜强情绪必须是原声，不能用旁白冒充

强情绪开场的核心不是AI写一句“情绪很浓”的文案，而是**当天真实录到的声音**。

可用：
- 客人突然笑得特别开心；
- “哇，这真的是我吗？”之类真实原话；
- 领证/生日/见家长等现场里情绪很明显的对话；
- 惊讶、尖叫、打趣、笑声、强互动。

最终输出必须明确标：

> （视频原声）“……”

或

> （现场原声）“……”

没有真实原声，不走方向2。

---

## 四、方向3｜强数字必须有画面证据

数字有意思还不够，必须能拍给观众看。

可用：付款、尾款、充值、客人数、复购次数等，但要有当天真实截图/页面/录屏/现场画面。

没有可展示证据就换方向，不把“听起来厉害”的数字写成开场。

---

## 五、方向4｜客人直入型，不强行让化妆师先当主角

如果没有方向1那类强工作室/本人画面，直接从客人坐下开始完全成立。

第一画面让观众看到客人的脸，然后第一句直接进入这次工作：

- 她今天去干什么；
- 她自己想要什么；
- 她最在意什么；
- 今天有什么变化值得看。

AI基于已经确认的主线最多给2个短钩子，不额外编事实。

---

# 六、结尾｜只有3—4秒，只做一句“人设尾巴”

正文和开场都确定后，轻问一次：

> 最后要不要顺手带一句你自己的记忆点？

## 只要命中预设方向，立刻给成品，不再追问解释

如果用户说出任何明确特点，例如：

- 负责任
- 定制化
- 审美高
- 很有礼貌
- 细节控
- 有耐心
- 会沟通
- 温柔
- 很稳
- 不敷衍
- 会替客人考虑
- 一人一妆
- 很懂普通女生

就不要再让她解释“为什么”。直接从预设库里给**最多2个**一句话版本。

结尾通常只有一个画面、3—4秒，所以禁止写成：

> “我化妆有个习惯，每个人的情况不一样，妆也不一样……”

这种是正文解释，不是结尾。

## 七、人设尾巴预设库

下面是内部方向库，按用户真实特点选，不是每次全部展示。

### 服务/责任
- 化妆超负责任
- 最会替客人操心
- 服务特别细
- 最不爱敷衍客人
- 超会照顾客人感受
- 特别会沟通
- 最有耐心

### 审美/适配
- 审美超稳
- 最会看人化妆
- 最懂普通女生
- 最会做适合本人的妆
- 坚持一人一妆
- 最会做减法
- 最会保留本人特点

### 工作习惯/专业
- 超级细节控
- 化妆特别较真
- 最爱反复确认
- 最会按场景定妆
- 最会替客人做取舍
- 绝不把所有人化成一个样

### 性格/关系感
- 超温柔
- 特别松弛
- 很稳
- 最有礼貌
- 最会哄客人放松
- 话不多但特别细

## 八、结尾句式骨架

优先短、稳、可重复。可按真实语气替换名字/称呼：

> 我是化妆超负责任的化妆师XX，今天就到这里，拜拜。

> 我是最会替客人操心的化妆师XX，今天收工。

> 我是超级细节控的化妆师XX，拜拜啦。

> 我是坚持一人一妆的化妆师XX，今天就到这。

> 我是最会看人化妆的XX，今天收工。

命中方向后**最多给2个版本**。

如果用户犹豫、说“不知道/算了/都行/不想加”，立刻放过：

- “今天就到这里啦。”
- “好啦，今天收工。”
- 或直接停在结果画面。

不要升华，不总结整条视频。

---

## 九、所有选择界面统一格式

凡需要学员选：独立分行、**粗体 + 数字编号**，最后一句“你直接回数字就行”。

但如果已经命中明确方向，不再制造选择题；开场/结尾最多给2个成品版本让用户快速确认。
