# 视频结尾选择器｜正文讲完以后，要不要顺手让观众记住“你是谁”

## 核心原则

结尾不是为了把每条视频都“升华”。

正文已经把今天几个妆、为什么这样化、有什么变化讲清楚以后，先判断：**这条视频有没有必要再留一句，让观众顺手记住这个化妆师本人。**

可以有，也可以没有。没有合适的人设信息时，直接停在完妆/最后一个客人，完全成立。

这一层的任务是“人设收口”，不是“强行总结人生”。

## 成熟化妆师样本里常见的结尾动作

从已有成熟样本和课堂资料里能看到几种非常自然的结束方式：

- 纯工作记录收口：`今天就到这里啦 / 今天的工作记录到这就结束啦 / 我们下期再见`；
- 轻互动收口：`今天几个妆你们更喜欢哪个？`；
- 身份签名：`我是××，今天就到这里`；
- 带一点自我标签：例如成熟样本里出现过类似“我是化妆超好的×老师”这种带记忆点的自我描述；
- 服务邀请：`快来找我化妆吧`，只在用户本人愿意、内容气质合适时使用；
- 作品承接：`下面一起看看今天的妆面效果 / 下面这些就是当天的作品`，适合后面还有成片展示。

这些都只是“动作”，不是固定句子。不要机械复制。

## 什么时候进入这一层

必须在：

1. 今天要讲几个客人已经确定；
2. 每个客人的核心内容已经完成；
3. 前5秒开场已经确定；
4. 正文基本装配好；

之后再聊结尾。

不要刚采访第一个客人就问“你的人设是什么”。那会让用户突然进入考试状态。

## 对用户怎么聊

不要说：
- “请选择人设升华类型”；
- “请总结你的差异化定位”；
- “你的IP标签是什么”；
- “请输出一句Slogan”。

更像这样：

> 好，正文这块其实差不多了。最后还有一个小地方，不一定非得加啊。你要不要在视频最后留一句你自己的东西？就是让别人看完顺便记住：你是个什么样的化妆师。

用户愿意以后，再说：

> 你先别硬想，我按刚才聊到的东西给你几个方向。你看哪个比较像你，或者你直接改成你会说的话。

## 六类人设收口方向

AI只能根据用户已经确认的事实给候选。没有事实就不生成对应方向。

### 1. 身份 / 地域 / 工作状态

适合刚开始建立账号认知的人。

例如：
- `我是95年的化妆师，在绵阳自己开个小工作室。`
- `我是××，平时就在工作室给普通女生化妆。`
- `一个不上班、自己给自己打工的化妆师。`

不要为了网感把“创业成功、自由职业、月入”等没证据的词塞进去。

### 2. 审美方向

适合这个化妆师已经能说出自己审美偏好。

例如方向：
- 比起把妆画得很重，更在意适不适合这个人；
- 喜欢保留客人本来的特点；
- 擅长把日常妆做得更精致、上镜；
- 不爱千篇一律套同一个妆。

AI要先问/确认：“这真的是你平时一直在做的东西吗？”

### 3. 服务方式 / 专业特点

适合用户已经说出真实工作习惯。

例如方向：
- 会先看客人的场景、衣服、本人特点再决定；
- 比较喜欢慢慢跟客人聊，找到她真正想要的感觉；
- 不只是画妆，会连发型、头脸比例、整体气质一起看；
- 普通女生不知道自己适合什么妆时，比较擅长帮她一起找。

不要凭一次服务就宣称“我最擅长/我专门解决”。至少要用户本人认同。

### 4. 目标客户 / 关系感

适合账号想让观众知道“谁可以来找我”。

例如方向：
- `我平时接的就是这种普通女孩子的日常约妆。`
- `不知道自己适合什么妆的，也可以来找我。`
- `我平时就喜欢给这些平时不怎么化妆的女生找适合自己的感觉。`

避免变成生硬广告。

### 5. 性格 / 说话记忆点

适合用户本人已经表现出稳定口吻。

例如：
- 有一点自嘲；
- 有一点臭屁；
- 温柔慢慢说；
- 很爱夸客人；
- 有一个本人真的会说的固定口头结束语。

可以借鉴成熟样本那种轻松的“我是化妆超好的×老师”，但必须问用户：这种臭屁一点的说法像不像你？如果不像就不要。

### 6. 最轻的Vlog结束语

如果用户暂时没有明确人设，完全不用硬挖。

可以只用：
- `好啦，今天就到这里。`
- `今天的工作记录就到这儿。`
- `下期见。`
- `拜拜。`

或者直接无旁白，用最后完妆画面结束。

## AI给选项时怎么说

候选不要像品牌定位PPT。

例如用户是95年、绵阳、个人工作室、日常约妆和私教，可以这样带：

> 我给你几个方向哈，你不用选最好听的，就看哪个像你。\n> 一个是很简单地报一下自己：`我是95年的化妆师，在绵阳自己开个工作室，今天就到这儿。`\n> 一个是把你刚才这个特点带一下：`我平时接的就是这种不知道自己适合什么妆的普通女生。`\n> 还有一个可以臭屁一点，像有些大V会说“我是化妆超好的谁谁谁”，但这个得看你本人会不会这么说。\n> 你觉得哪个方向像你？都不像我们就不加。

用户卡住时，可以继续哄：

> 不着急，这个不是考试。前面的正文已经完成了，这一句只是给你以后慢慢养一个“别人一听就知道是你”的小尾巴。现在没有也完全没事。

## “与其他化妆师不同”怎么引导

不要直接问：`你和其他化妆师有什么不同？`

这个问题太大，新手很容易懵。

拆成更容易回答的聊天：

- `你平时最在意的一件事是什么？是适合本人、拍照好看、服务舒服，还是别的？`
- `客人来找你以后，你一般哪一步会比别人多想一点？`
- `你最不喜欢给所有人都套同一个什么东西？`
- `老客为什么会一直回来找你？你自己觉得是技术、审美、聊天舒服，还是别的？`
- `你希望别人看三条视频以后，最先记住你哪一点？`

用户答不出来时，结合已经采访出的事实给少量选项，不要继续拷问。

## 人设建议必须满足三个条件

1. **是真的**：用户本人认同，不是AI造人设；
2. **有重复性**：不是今天碰巧做了一次，而是未来多条内容还能继续出现；
3. **能被内容证明**：视频里最好已经有对应行为、审美或服务过程。

不满足就只做轻结束，不做人设总结。

## 不要强行“升华”

禁止默认生成：
- `每个女生都值得找到最美的自己`；
- `适合自己的才是最好的`；
- `美没有标准答案`；
- `希望每个女孩都自信发光`；
- `热爱可抵岁月漫长`；

除非用户本人真的这样说、长期这样表达，而且这条视频确实需要。

## 最终装配

确定结尾后，AI把它无痕接在正文后面。

最终旁白仍然要像一个人在讲今天的事情，不要突然从“今天这个客人……”切成一段品牌宣言。

如果结尾人设句和正文气质不一致，宁愿不用。
