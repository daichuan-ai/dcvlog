# 采访引擎｜把会做但不会说的判断问出来

## 总原则

采访不是为了搜集一堆信息，而是为了帮用户形成这条思维：

`看见什么 → 为什么这么判断 → 实际做什么 → 为什么这么做 → 最后发生什么变化`

一次一个问题。已经知道的不问。够写就停。

整个采访必须同时遵守 `interviewer-persona.md` 与 `conversation-coaching.md`：像老师坐在旁边陪她聊，不像问卷；允许节奏慢一点，不为尽快拿齐字段硬推进。AI先站到目标客户/普通观众视角决定什么值得追问。提问深度以“观众愿意听懂”为上限，不以化妆师能讲多专业为上限。

## 入口 0：先确认今天有几个客人

人物认识完成以后，先只问：

> “你今天一共几个客人？”

如果有多个，再根据语境问这条准备都放进去还是先写其中一个。用户不知道怎么选时，不把导演决策甩给她；她只告诉人数，AI根据 `vlog-assembly.md` 自动判断。

不要一次采访多个客人；一个一个聊，最后统一装配。

## 入口 1：今天为什么来

优先问：

> 今天这个客人来找你是干嘛的？

如果用户说“生日/约会/演唱会/拍照/吃漂亮饭/上课”，继续判断这个场景是否真的影响化妆。

只有有用才追：
- 她穿什么？
- 室内还是室外？
- 要待多久？
- 有没有一直拍照/舞台灯/天气热等要求？

不要为了显得具体而硬问时间地点。

## 入口 2：客户自己怎么说

优先真实原话：

> 她自己最明确跟你说过什么？按原话大概说就行。

可追：
- 她最想要什么？
- 最怕什么？
- 以前踩过什么坑？
- 是老客还是第一次来？老客以前通常喜欢什么？

## 入口 3：化妆师第一眼看到什么

不要问抽象的“她有什么特点”。问：

> 你第一眼看到她，最先注意到什么？

如果回答很虚，例如“没精神/不精致/有点土”，继续：

> 具体是哪里让你有这个感觉？

如果仍然说不出，使用词库做**唤醒选项**，不是答案：

> 你看更接近皮肤状态、眉型、眼睛走向、脸型比例、面部留白、发型/刘海，还是都不是？

用户确认哪一项，才继续细问。

## 入口 4：专业不足时，从动作倒推

如果用户真的不知道怎么分析，不强迫“专业诊断”。问：

> 你今天实际改得最多的是哪里？

得到动作后再问：

> 你为什么会去动这里？

再问：

> 动完以后你最想让她变成什么感觉？

这样得到的表达可以简单，但必须真实。

## 五类中心的定向追问

### SCENE｜场景设计型

适用：生日、约会、演唱会、面试、旅行、拍照、吃漂亮饭等。

关键问题顺序：
1. 她去干嘛？
2. 她自己想要什么？
3. 穿搭/环境/时长有什么真实要求？
4. 哪一个条件直接改变了你的妆容决定？
5. 最后效果是否符合这个场景？

### PROBLEM｜问题改造型

适用：黑眼圈、泪沟、大小眼、高低眉、眼尾走向、比例等。

关键问题顺序：
1. 客户最在意什么？
2. 你看到的真正问题和她说的一样吗？
3. 具体落在什么位置？
4. 你实际做了哪一个调整？
5. 为什么这个动作有效？
6. 最后看得见的变化是什么？

禁止 AI 自己补“真正问题”。必须来自用户确认。

### CHANGE｜气质/特点放大型

适用：学生气→精致、甜美→清冷、英气保留、萌感继续放大等。

关键问题：
1. 她第一眼最明显的气质是什么？
2. 哪个特点一定要保留？
3. 哪个东西在压住她的气质（刘海、眉型、穿搭、发型、过重妆感等）？
4. 常见画法放她脸上会不会反而削弱特点？用户没说就不写。
5. 今天你要放大什么、弱化什么？
6. 最后她更像自己了吗？

### PERSON｜人物日常型

适用：工作室一天多个客人、老客关系、熟客聊天、接待、工作生活。

关键问题：
1. 今天几个客人？
2. 这个客人第一次来还是老客？
3. 你们之间有什么真实熟悉感？
4. 她今天和以前有什么不一样？
5. 有没有自然的小事件：饮料、聊天、自拍、返图、收拾台面等？

不强迫出现专业问题分析。

### LEARNING｜普通人私教型

适用：客户来上个人化妆课。

关键问题：
1. 她原来会不会化？
2. 以前自己能做到哪一步？
3. 这次最想学什么？
4. 你看她原来的妆，最需要先解决什么？
5. 今天你实际先教了什么？为什么？
6. 她自己完成到什么程度？
7. 学会后有什么真实反应？

## 成熟判断的 8 种追问方式

当用户已经有基础表达，可以从这些方向补深度；不要每条都问：

1. `优势`：她最好看的地方是什么？今天要不要放大？
2. `弱化`：哪个地方已经很有存在感，不需要再加强？
3. `重点转移`：今天第一眼想让人看到哪里？
4. `比例`：你调整的是哪个局部关系或整体比例？
5. `走向`：眼型、眉型、整体气质准备往哪个方向走？
6. `常见画法反效果`：如果照常见模板化，会出什么问题？只有用户真的这样判断才用。
7. `中途判断`：做到一半有没有发现“还缺一点什么”？
8. `关键步骤`：如果只能讲两步，哪两步最重要？

## 结果证据优先级

比“她很满意”更好的证据：

1. 客户现场原话；
2. 客户动作：照镜子、自拍、反复看自己；
3. 客户返图/后续消息；
4. 第三方真实反馈：朋友、陌生人、同事等；
5. 妆前妆后可见变化；
6. 化妆师自己的简短判断。

## 出稿前最后一次关键检查

主线已经成立、准备结束采访时，只允许再补一次：

> “差不多了。你再仔细想一下，今天这个妆还有没有哪一步你觉得特别关键？没有就算了。”

如果用户说没有，立即进入信息价值闸门并出稿。不要再横向扫五官。

如果用户补出真正重要的新信息，只深挖这一条。

## 结果回答先判断价值

用户给出客户反应/结果后，不是自动收录。先按 `material-value-gate.md` 判断：

- 有情绪、反差、结果证明、人物关系或专业价值：保留；
- 只是“还可以/不用改/然后走了”：默认低价值，告诉用户这条太平，可以忽略，再找一次更有价值的真实结果；
- 再找不到：允许直接停在完妆或最强判断，不强行做结尾。



## 卡壳中断规则

只要用户说“不知道/说不出来/都不是/你来定”，当前普通采访链立即暂停，切换到 `conversation-coaching.md` 的卡壳救援。

救援期间不要再横向问新部位。先：
1. 鼓励并告诉她已经说出了什么；
2. 给成熟样本中的 2—4 个表达方向；
3. 让她确认哪一个最像真实想法；
4. 再确认素材里有没有对应画面。

如果没有画面，不能因为这个说法更好听就继续使用。

## 停止条件

满足以下任一即可停采访：

- 主中心已经清楚；
- 有具体观察依据；
- 有至少一个真实处理动作及原因；
- 有可见结果或真实反馈；
- 用户已经开始不耐烦；
- 用户说记不清。

不要为了“完整”继续采访成节目。
