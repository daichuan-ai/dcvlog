# Batch 001｜第一批成熟化妆师基准案例｜LOCKED

状态：锁定基准语料。

说明：这里保存的是当前 DCVlog 已经吸收并反复验证过的第一批成熟表达母案例。后续新案例不得覆盖这些案例，只能在新批次中新增并比较。

> 这里学习的是“叙事行为”，不是照抄句子。

## B001-01｜场景：生日 / 拍照

核心行为：

`今天要过生日/拍照 → 客人想更有仪式感或更上镜 → 比普通日常多一点明确度 → 只处理真正影响镜头的部分 → 结果回应生日/拍照场景`

可学习点：场景本身就能做主线，不必强行改成五官问题。

## B001-02｜场景：领证 / 见家长 / 面试

核心行为：

`真实场景要求 → 客人想自然/亲和/利落 → 不做太重 → 状态做干净、精神 → 结果`

可学习点：专业判断可以很少，场景已经足够解释服务决定。

## B001-03｜客户需求：不要太浓 / 自然一点

核心行为：

`保留客户原话 → 不追求大改造 → 只处理真正影响状态的地方 → 客户接受/满意`

可学习点：普通人的话本来就是内容，不必翻译成术语。

## B001-04｜客户不知道自己适合什么

核心行为：

`客户没答案 → 化妆师先做一个保守而明确的服务决定 → 只动1—2个最关键地方 → 客户反馈`

可学习点：不能写成“客户不知道，所以做完整面部诊断”。

## B001-05｜问题：一化妆就显成熟

核心行为：

`客户困扰 → 找到真正造成困扰的一两个特征 → 如果继续加重会更糟 → 反而做轻 → 结果`

可学习点：成熟感来自知道哪里不要继续画。

## B001-06｜变化：甜感太重，今天想换方向

核心行为：

`原来一直是什么风格 → 今天明确想换 → 原本哪些特征会把她拉回旧方向 → 不继续强化旧方向 → 结果`

## B001-07｜浓颜做减法

核心行为：

`先承认本身优势 → 点出堆叠风险 → 不再全部加强 → 只留本人特点 → 结果`

## B001-08｜没有明显缺点，但没记忆点

核心行为：

`哪里都不差 → 真正问题是平均 → 不每个地方都用力 → 抓一个优势做视觉重点 → 结果`

## B001-09｜多客人工作 Vlog

核心行为：

`工作日常/最强客人 → 第1位讲故事 → 一句桥接 → 第2位只讲最强新点 → 第3位只带需求/特点与结果 → 第4位以后画面优先 → 自然收工`

内部记忆：**第1个讲故事，第2个讲重点，第3个以后看结果。**

## 第一批案例的固定学习项

每次拿本批案例做参考，只学习：

- 从哪里进入人物；
- 场景/需求/问题/变化谁做主线；
- 专业判断什么时候出现；
- 哪些步骤敢删；
- 结果如何回应开头；
- 一句话承担多少信息；
- 什么时候停；
- 同类型大概写多长。

不得移植样本中的人物事实、客户反馈、金额、场景细节或专业结论。
