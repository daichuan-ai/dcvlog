# DCVlog 成熟案例库索引

Corpus Version: `1.0.0`

这套案例库和 Skill 逻辑版本分开维护。

- Skill Version：控制采访、写稿、拼图、开场、结尾等运行逻辑。
- Corpus Version：控制当前参考的成熟化妆师真实案例与从案例中提炼出的表达规律。

## 当前批次

### Batch 001｜baseline｜锁定

路径：`batch-001-baseline/cases.md`

状态：**LOCKED**

用途：保存第一批已经反复讨论、验证过的成熟化妆师案例与母逻辑，作为稳定基准。

规则：
- 不因为后来出现新玩法就覆盖、改写或删除原案例；
- 允许补充来源说明、编号和统计信息，但不改原案例事实；
- 它负责让 DCVlog “不会写坏”。

### Batch 002｜new｜持续更新

路径：`batch-002-new/`

状态：**OPEN**

用途：以后代川发现新的高流量表达、新开场、新叙事、新长度、新服务故事时，持续放进这里。

规则：
- 新案例先收录，不自动升级为永久方法；
- 原始文案与 AI 总结必须分开保存；
- 累积到一批后，再通过“扫描新案例库，升级当前方法”集中比较；
- 它负责让 DCVlog “不会写旧”。

## 写稿时的读取优先级

1. 先读 `current-patterns.md`，知道当前被验证的表达规律；
2. 再从 Batch 001 + 已启用的新批次中找与本次内容最接近的案例；
3. 结构、信息进入顺序、句子密度、停止位置和长度向成熟案例靠；
4. 事实、客户原话、专业判断必须来自本次采访；
5. 新旧案例冲突时，不机械平均：先判断是否属于平台表达变化、内容类型差异或样本偶然性；
6. 任何新案例都不能覆盖“真实事实、证据边界、不编专业判断”等硬规则。

## 维护口令

代川在维护环境中可以直接说：

- `扫描新案例库，升级当前方法`

具体维护规则见 SKILL.md 的“案例库维护模式”。
