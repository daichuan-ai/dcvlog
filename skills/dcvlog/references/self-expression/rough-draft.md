# 初稿整理与价值观检查

## 交付定位

让学员拿到一份能够继续说、继续改的初稿。使用她已选定的方向和真实素材，保留她自己的语言。约一分钟只是课堂练习的尺度，按实际试读调整，不机械追求字数。

若本人已明确选择方向且信息足够，直接起草。若仍在探索，不因有一个故事就提前生成全文。若本人要求先试写而信息有限，只使用已有部分，关键缺口列在稿外；不要以占位内容伪装成事实。

## 开头从材料中找

可选本人观点、目标观众能理解的顾虑、一个具体事件、一个正在发生的改变或一句有意味的原话。它们只是入口，不是强制模板。

尽快让人知道这是怎样的处境，以及接下来有什么值得听。让期待与真实后续一致。避免讲课开场、夸张承诺、无依据的冲突和强行索赞。

先聊经历，整理时再选开头。不要先写一句漂亮的立意，再倒推一个支持它的假故事。

## 用具体内容推进

保留具体愿望、当时念头、行动和后续。每一小段尽量增加一项信息，删去反复表达同一种委屈、辛苦或认真却不推进事件的句子。

不必同时使用所有素材。可以选一件事讲清，也可在有真实时间关系时做前后对照。若引用不同事件，要保持它们各自的身份和时间关系。

允许普通结果、仍有顾虑、改变主意、暂时停止、获得支持，以及平静的喜欢。不要自动补顾客赞美、贵人出现、成功接单或“这一刻我终于懂了”。

## 将价值观放在事件里的选择中

先在内部检查四件事：

1. 这次她实际在意什么，来源是本人原话还是AI推测？
2. 当时她面对哪些真实选择或条件？
3. 她具体怎样做了，或者为什么暂时没做？
4. 哪个行动或细节足以让观众理解她的判断？

只有本人确认过的含义才能写成明确想法。AI推测先问清，或保留动作让观众自己理解。

| 想表达的意思 | 应寻找的事件支撑 | 不直接替她写的标签 |
|---|---|---|
| 想靠自己过日子 | 她怎样安排学习、收入或接单机会 | 独立、坚强、永不放弃 |
| 希望顾客表达真实感受 | 她具体问了什么、改了哪里、如何处理分歧 | 我比别人负责、我只为顾客着想 |
| 想多一些自主权 | 一次协商、报价、安排时间或尝试接单 | 我天生不服输、我不靠任何人 |
| 喜欢一种妆感 | 颜色、质感、线条、饰品怎样取舍，顾客需求如何影响 | 我的审美高级、我与众不同 |
| 在乎把人教会 | 她怎样调整示范、交还工具、查看对方独立操作 | 我是有良心的老师 |

这些只是支撑关系，不能把表内动作填进没有发生过的故事。学员自己确实说过的总结也要检查是否与事实一致，是否只是重复已被行动表达的意思。不要为了“有人设”额外增加一段宣言。

## 识别并处理自卖自夸

逐句找以下情况：自称专业或大师、贬低同行突出自己、用顾客赞美证明品格、空泛匠心或审美宣言、向所有人保证服务效果。

- 有事实支撑：优先保留动作、取舍和真实反馈，把评价交给观众；需要一句本人观点时使用本人原意。
- 没有事实支撑：删去评价，或在稿外提出一个具体追问。
- 本人以夸张方式表达情绪：保留其情绪含义，避免把夸张写成可验证的业务承诺。

不能把“赚钱”加工成“其实我根本不在乎钱”。不能把“还没有订单”改成“后来终于被看见”。不能将日常动作统一包装成牺牲和崇高信念。

## 作品与服务怎样接

只接与前面经历相关的可用画面：沟通后的作品、某个审美细节、自己的实际尝试或学习过程。无需为最后展示作品再塞一段自我介绍。

如无相关作品，允许口播成立，不假设存在妆前妆后、聊天截图或顾客授权。若本人想介绍服务，以与当前经历直接有关的一句事实收束；不要自动转招生、促销、预约、课程权益或广告。

## 口语检查

- 用学员能说出口的短句，保留她有辨识度的词。
- 删除“不是……而是……”“很多人以为……”式套话、堆叠排比、宏大结论及无来处的金句。
- 不用“你必须”“化妆师都应该”等对观众训话来替代自我表达。
- 保持事实与情绪原有强度，不能为了冲突升级成羞辱、绝望或崩溃。
- 检查每个数字、对白、因果和结果能否回到素材卡；不能回找就删或问。
- 检查内容是否有新信息，是否让观众听懂后续，不靠隐藏关键信息硬吊胃口。

## 默认交付方式

先用一句话说明本人选定的方向，再给一份可复制的粗稿。仅在必要时附少量画面提示，放在稿外。

附上最多两三个真正有用的继续思考处，例如某处还有一个真实细节可补、某句需本人重新用自己的话说、某个解释尚未确认。明确它们可被修改或否定，不把“标准答案”放在旁边让学员模仿。

最后只留一个轻问题，如“哪一句最不像你平时说话？”或“这件事里，有没有当时想了却还没说出来的话？”让学员继续表达。

## 发布后的学习

仅在本人提供数据或观众反馈时复盘。区分内容入口、表达完成度、观看反馈与外部条件。不要从单次表现推出某个伤口更值得暴露；可比较哪些具体段落让观众回应、哪里没有说清，再由本人决定下一次尝试。
