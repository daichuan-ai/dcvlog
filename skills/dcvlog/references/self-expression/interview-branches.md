## 使用方法与共用追问

把分支用于倾听和选下一问，不把它们作为人设类型贴给学员。允许一段经历连到多条线；保持事件来源独立，稍后比较讲述中心。对不吻合的主线及时离开。

先理解本人，再提问。问题顺序可变，不要每个事件机械问完全部字段。以下问题每次只挑一个：

- 找事情：最近哪一次让你有这个感受？那次发生了什么？
- 找愿望：那时候你最想得到或改变什么？
- 找当时念头：先不总结成长，那一刻你脑子里第一句话是什么？
- 找取舍：你当时考虑过哪些做法？是什么让你最后这样选？
- 找动作：后来你具体做了什么？也可以是暂时没处理。
- 找后续：实际结果怎样？现在还在影响你吗？
- 找变化：回头看，你还认同当时的想法吗？

有情绪时先留住它，再问对应的细节；没有明显情绪也可沿着选择、习惯和小变化聊。不要把哭泣当完成条件。先用开放问题；学员卡住时才给两三个轻提示，并明确“也可能都不是，你按自己的情况说”。

## A：想靠手艺改善生活

### 入口

听到入行、换工作、学费、第一笔收入、想多挣钱、生活安排、想被认可时进入。先问她自己的期待，允许动机普通、偶然或混合。

可问：当初学化妆，你最希望它改变生活里的哪件事？

### 分支

| 线索 | 下一层可以问 | 继续回忆的方向 |
|---|---|---|
| 赚钱 | 当时为什么选择靠化妆赚钱？ | 可选机会、当时条件、期待和实际差别。 |
| 钱的具体意义 | 多挣一点以后，你最想先改变哪件事？ | 生活开销、喜欢的东西、储蓄、家庭、自主安排；不要求金额和高尚理由。 |
| 想证明自己 | 有没有一件具体的事，让你特别想做出点样子？ | 谁的看法、自己的期待、当时有没有回应；不预设家人反对。 |
| 想自由一点 | 你当时希望一天怎么过？现在有哪些变化？ | 坐班、自己接单、带娃、休息、时间安排；不预设创业一定更自由。 |
| 已经做熟了 | 现在继续做，最现实的考虑是什么？ | 手艺积累、重新开始的成本、喜欢的环节、仍在尝试的改变。 |
| 期待落空 | 哪次让你发现和原来想的不一样？ | 当天发生什么、当时想法、后来做法，不自动写成失败史。 |
| 有一点进展 | 哪个小变化，让你觉得这条路还可以继续？ | 一笔收入、一个动作、一次自己做主，保留真实规模。 |

### 转线与联系

若谈到没人看作品，转B；若谈到老师派单，转C。家庭或经济细节不愿讲时，转工作中的具体事情。已聊充分就暂存，不要求挖到更早、更痛的往事。

比较时关注：想改变的事情是否具体，普通观众能否理解愿望与实际条件。价值观通过她怎样安排时间、收入和机会出现；不要替她加“独立坚强、不服输”的总结。

## B：手艺信心与经营回报的落差

### 入口

听到“我化得不错，但没流量、没人咨询、订单少、收入没上去”时进入。先确认落差发生在哪一步，不把全部原因归为平台，也不反过来训她技术不好。

可问：最近一次让你觉得“明明做得不错，却没得到回应”，是哪件事？

### 分支

| 线索 | 下一层可以问 | 继续回忆的方向 |
|---|---|---|
| 对技术有信心 | 哪次作品或顾客反馈，让你对这方面比较有把握？ | 她最满意的具体部分，实际反馈，自己的判断。 |
| 作品没人看 | 那次你原来期待什么？发出去以后发生了什么？ | 准备过程、真实数据或主观感受分开、第一反应；不索要证明式截图。 |
| 有人看但没咨询 | 你怎么发现这个差别的？有哪次印象深？ | 内容里展示什么、顾客理解什么，保留未知原因。 |
| 有咨询没成交 | 能回忆一段最近的咨询经过吗？ | 对方问什么、自己怎样回复、价格与需求、失联也可如实结束。 |
| 做得忙但收入有限 | 哪一次算账或安排工作，让你有这个感觉？ | 时间、收入和精力的实际取舍，不替她推断被亏待。 |
| 与同行比较 | 你最在意对方的哪一件事？当时对自己怎么想？ | 被羡慕、羡慕别人、自我怀疑、尝试学习，不评价谁配不配。 |
| 不敢被看见 | 最近一次想发又没发，停在哪一步？ | 熟人目光、声音、形象、怕没有回应，也可能只是忙。 |
| 已经做过尝试 | 你改过什么？哪次尝试让你记得？ | 拍作品、咨询表达、练习、学习、换方式，允许没结果。 |

### 转线与联系

若只剩平台不给流量的重复结论，先标记原因未知，找一次真实尝试或转其他线。若主要关切是价格由别人定，转C；若最在意怎样对顾客，转D。

比较时关注：认真投入与结果之间的具体落差，普通人能否理解“我试了，却暂时不知道哪里不对”。价值观通过她面对结果怎样问、改、试、暂停来显露，不把自我评价升级为实力认证。

## C：派单合作与自主空间

### 入口

听到老师、工作室、团队派单、合作结算、报价、客户归属和时间安排时进入。保留合作收益和限制两面，避免预设压榨、背叛或必须单干。

可问：现在的接单方式，哪些地方帮到了你，哪些地方是你想调整的？

### 分支

| 线索 | 下一层可以问 | 继续回忆的方向 |
|---|---|---|
| 起初依靠派单 | 最初为什么选择这种合作？ | 客源、收入、学习机会、稳定，承认得到的帮助。 |
| 价格不能决定 | 最近哪次报价或结算，让你有感受？ | 谁决定、具体经过、本人如何理解；不了解部分标未知。 |
| 时间不能决定 | 有没有一次安排，你想改又没改？ | 现实选择、担心的后果、实际沟通，不预设不敢拒绝。 |
| 顾客只记得团队 | 你希望顾客对你多了解哪一点？ | 具体服务、名字或作品如何被展示，分清事实与猜测。 |
| 想自己接单 | 这个想法是从哪次事情开始的？ | 想争取的决定权、愿意做的改变。 |
| 想走又担心 | 你目前最需要保住什么？又最想改变什么？ | 收入、关系、能力、客户来源，不把犹豫视为软弱。 |
| 已开始尝试 | 第一件实际做的事是什么？后来怎样？ | 协商、试接个人订单、学表达、调整时间，也允许尝试后留下。 |
| 合作很满意 | 哪一点让你愿意继续合作？ | 一次被支持的经历、个人选择和工作乐趣。 |

### 转线与联系

不愿公开合作关系，就用可匿名的自身选择或转线。对原因缺证据时不补写他人动机。满意合作时沿收获和选择聊，不继续寻找隐藏委屈。

比较时关注：稳定与自己做主之间的取舍，行动如何受现实条件影响。价值观可以体现在协商、拒绝、尝试或继续合作，不设离开团队为正确结局。

## D：服务判断、审美与普通正向经历

这些入口同等有效。无苦难、没有强烈改变诉求、偏爱轻松表达时优先使用。

| 方向 | 开口问题示意 | 再深入一层 | 价值观出现的位置 |
|---|---|---|---|
| 顾客意见与自己判断 | 最近哪次服务让你调整了原来的想法？ | 她说什么，你原来怎么想，后来改了什么？ | 决定权、沟通与实际修改。 |
| 价格与关系 | 哪次谈价让你印象深？ | 当时顾虑什么，最终怎么说、怎么做？ | 人情、工作收入和边界的取舍。 |
| 服务出现偏差 | 哪次做完后，你还在回想哪里没接住需求？ | 怎么发现、怎样处理，现在有无改变？ | 承认和修正，不包装永不犯错。 |
| 审美偏好 | 最近哪个作品细节让你很想多看几眼？ | 为什么保留它？现场有没有别的选择？ | 颜色、质感、线条与整体主次的实际选择。 |
| 浓淡与人的特点 | 哪次你和顾客一起确定妆感，让你记得？ | 她想什么、你喜欢什么、怎么磨合？ | 可以浓、淡、华丽或利落，不设自然妆为优越标准。 |
| 学习变化 | 最近学会什么，让工作少了一个麻烦？ | 以前卡哪、怎样练、实际改变了什么？ | 愿意投入的地方和认知变化。 |
| 普通正向经历 | 最近哪一小段工作，让你觉得这一天过得不错？ | 一个动作、一句话、为什么对你有意思？ | 成就感、喜欢的相处方式和生活选择。 |
| 不想总结观点 | 哪件小事你只是想记下来？ | 当时看到或做了什么？ | 允许不归类，先保留具体经历。 |

## 难回答时的接法

- “赚钱呗”：接住，再问为什么选这门手艺或现在最想改善哪件事；不急着补热爱。
- “我很努力”：问最近一段时间一天具体在做什么；不自动写凌晨练习。
- “没什么故事”：缩小到最近一次预约、咨询、练习或准备发布的时刻；不寻找悲惨童年。
- “我就是大师”：听清她希望被看见的能力，问一件支撑判断的工作；不要附和认证或羞辱反驳。
- “没有不顺，过得不错”：沿喜欢的工作环节、合作收获或审美选择聊。
- “不想说这个”：停在她愿意保留的范围，换一条线，不追问拒绝原因。
- 一次给很多材料：先分开事件、简短复述，再选一个最值得补的问题；不把其他线索丢掉。
