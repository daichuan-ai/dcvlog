# 方向比较与推荐

## 先满足条件

将方向定义为这一次最想让人理解的处境、选择或个人看法，不定义成一套文案段落。先检查：

1. 核心材料真实，关键因果没有由AI补全；未知事实仍标未知。
2. 本人愿意按相应范围表达，方向符合本人的意思。
3. 有具体经历、动作、偏好取舍或变化支撑；只有人格标签时继续补问。
4. 候选有不同讲述中心。不要把同一个故事改三个标题充当多个方向。
5. 尚不足的候选标待补问，不以想象中的完整故事与成熟材料比较。

不要把真诚、公开意愿和本人意图作为可被高传播分数抵消的项目。

## 比较六件事，不计算虚假的流量分数

| 维度 | 根据材料怎样判断 |
|---|---|
| 本人意义 | 她为什么在意，反复提到哪里，是否确实想先说。 |
| 大众入口 | 没做过化妆的人能否理解她想要什么、怕什么、为什么犹豫。 |
| 继续看的理由 | 观众可能想知道后面怎样处理，这个期待是否有真实后续回应。 |
| 具体程度 | 场景、原话、动作、选择、结果哪些已经清楚，缺什么。 |
| 首条可讲性 | 背景是否简明，她是否熟悉，能否用自己的话说清。 |
| 人物判断 | 能否看见她在这件事里怎样选择，而非换个人也成立的口号。 |

把传播判断作为创作假设，用实际材料说明“更容易理解”“后续更明确”“这条更适合先讲”。不要声称某阶层人数多所以必然爆、只有弱者有流量、只要感动自己就会打动所有人。

大众入口可以是想多挣一点、在意认可、认真做却暂没结果、想试又怕、稳定与自主之间的选择、一次小进步、对美的具体发现。苦难程度、贫穷、性别、哭泣和成功逆袭都不加分。

## 比较输出

通常列两到三个候选，使用简洁文字或小表格。每个候选包含：

- 方向：这一条想让人理解什么。
- 真实支撑：来自哪一两件事或原话。
- 共鸣入口：同行以外的人可能怎样理解。
- 当前缺口：哪些要补，或已经足以开始。

随后明确推荐一个先讲的方向，给两条与材料有关的简短理由，同时说明其他方向适合什么表达目的。表格已经说明的经历不再逐段重复。不要一律推荐最委屈的一件。

如果本人最想讲的与推荐不同，说明取舍后让本人选。她选定后就沿那个方向帮助表达，不能反复以“没流量”否定她。

只有一个成熟候选且本人希望收束时，说明比较范围有限，给暂定方向；不得凭空创造其他经历来凑齐选项。

## 推荐示意：只示范判断，不给学员编经历

假设本人已经提供以下真实材料：

- E01：与熟人谈收费，记得当时对话、犹豫、最终处理。
- E02：准备从团队接单转为自己接单，但目前只有泛泛想法。
- E03：偏爱保留雀斑，有一件具体作品，但尚未讲为什么保留。

可以建议先考虑E01，依据是关系与钱的顾虑容易理解，经过也较完整。E02对本人意义可能更大，补一次实际尝试后再判断。E03可以继续聊现场取舍，适合表达审美。

如果本人明确最想讲E03，就追问那次作品的实际决定，再找普通人能够进入的感受；不能将其改写成被否定后的逆袭。

## 定方向之后

记录本人选定内容及理由，用一两句普通话描述想表达的中心。允许换切入口、换事件重点、把暂时不认同的解读删掉。

只补会影响事实和理解的关键缺口。已存在来源的事实不反复审问。确定后进入粗稿；不要继续逼学员认同固定句式、标准立意或必须感动的结尾。
