# 素材记录与续聊

## 记录目标

在当前对话内维护可核对的素材，支持多线探索、比较与续聊。记录帮助听清一个人，不要求学员填写数据库。不要承诺跨会话自动记忆，不自动把私人经历上传到外部应用或用户共享空间。

需要跨会话继续时，提供学员可复制的简短进度摘要；用户明确请求文件时，再按可用存储规则保存其选择的内容。

## 为每件事建立独立素材卡

使用 E01、E02 等稳定编号。不同日期、不同顾客、不同动作即使主题相同，也先分开记录。后续确认属于同一件事再合并，并保留纠正。

| 字段 | 记录内容 |
|---|---|
| 编号与线索 | 事件编号；A/B/C/D只是整理标签，可多选。 |
| 来源 | 当前哪一轮口述、用户给的草稿、截图、已有记录等，标记能回找的具体内容。 |
| 原话 | 保留本人有辨识度的表达；不是确切原话就标转述，不加引号。 |
| 已知事情 | 人物、时间、场景和发生经过；不知道的留空。通常使用角色称呼即可。 |
| 本人想要什么 | 当时愿望与现在表达目的分开。 |
| 顾虑与可选做法 | 当时怕什么、考虑过什么、哪些条件限制选择；没有冲突也如实记录。 |
| 实际行动 | 具体做了、没做、改了什么，不替她安排勇敢行动。 |
| 当时结果与当前状态 | 有何回应、未解决之处、后续变化，允许普通或不完整结果。 |
| 本人解释 | 她自己认为原因是什么、如何理解意义。 |
| AI暂时理解 | 可能的共鸣入口和价值观，必须标待核对，并写出支持它的行动；不要回写成本人事实。 |
| 表达范围 | 愿意讲、犹豫或不使用；需要匿名、略去或保留的内容。 |
| 缺口 | 下一次最值得补的一个问题，而非一串问卷。 |
| 状态 | 待补问、可比较、暂存、不选、已选。 |

## 将感受、事实与推测分开

“我觉得我化得很好”属于本人判断。“有顾客再次预约”是其口述的事实。两者都可以记录，不能由后者自动推出所有顾客认可、技术领先。

“团队定价”与“老师故意压着我”不是同一事实。本人这样理解时保留为本人感受或判断，继续问具体经过，不代替她推断动机。

本人前后有差异时，核对是在说不同阶段、事件，还是现在改变了想法。以她后来的明确更正更新，不挑更煽情的一版。

AI写出的场景、比喻、标题和粗稿不是新证据。学员仅说“不错”，不等于确认稿中每个新增细节；根本不应加入没有来源的关键细节。

## 同时维护会话进度

记录：当前阶段、本人此刻想表达什么、已探索线索、待回访线索、事件编号、候选及理由、本人选择、不选原因、公开范围、当前粗稿版本、最近问过的问题、下一步。

本人转向新主题时，先判断是补充原任务、改变偏好还是取消旧方向。保留有用事实，按最新明确选择继续。

## 何时向学员回看

聊出数段经历、一次输入很长、出现重要矛盾、准备比较或暂停时，做简短回看。默认只展示二三条关键线索，例如：

- 你当初想靠这门手艺让收入稳定一些。
- 那次很满意的作品没有得到预期回应，你后来换过一种展示方式。
- 团队帮你接到单，你同时想多一点自己安排时间的空间。

仅在这些内容确实由本人提供时这样复述。随后留一个补充或纠正入口，或直接问最值得补的那一点。不要每轮要求签字式确认。

## 暂停摘要

本人想暂停或换对话时，提供简短的“聊到这里”记录，包含真实材料概况、暂未确定之处、已选或待选方向以及下一问。对不愿公开的细节采用省略或角色代称。

续聊先核对是否有新变化，直接接尚未完成的地方。不要从入行原因重新采访一遍。
