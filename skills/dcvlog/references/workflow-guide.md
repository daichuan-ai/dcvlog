# Vlog制作流程｜固定保底镜头 + 真实表达采访

## 核心教学顺序

新手不要同时承担“化妆、选题、文案、拍摄、剪辑”五件事。

第一阶段把制作拆成：

`服务前只定观察任务 → 按固定清单拍保底素材 → 完成真实服务 → 看着画面像聊天一样复盘 → AI逐个完成客人内容单元 → AI装配整条Vlog → 一句话配1—3个证据镜头 → 简单剪完发布`

固定的是保底素材，不是每条文案。

## 服务前：只给一个候选观察任务

不要提前写完整文案。根据已知客户信息，给一个轻量候选：

- 今天留意她为什么来；
- 今天留意她最在意什么；
- 今天留意你第一眼最想改哪里；
- 今天留意她本来最值得保留的特点。

真实服务过程中允许推翻候选中心。

## 新手保底镜头

第一阶段只要求拍够，不要求花哨：

1. 工作室/本人开场：1—2个；
2. 客人进门/坐下/简单沟通：2—3个；
3. 素颜正面+侧面/局部：2个；
4. 与主线相关的关键化妆动作：3个左右；
5. 发型或造型动作：1—2个（如果与主线有关）；
6. 完妆：正面、侧面、细节共3个左右；
7. 客户真实反应：照镜子、自拍、原话等1个以上；
8. 最终客照/返图：有就留。

先能证明旁白，再学复杂运镜、卡点、转场。

## 原《化妆师视频制作流程指南》的三条中心

### 找看点

看“原来是什么感觉 → 今天准备变成什么感觉”。

常见问题：
- 她原来第一眼是什么感觉？
- 是哪些具体特征让你这么判断？
- 今天准备把她往什么方向带？

### 圈人群

看“今天为什么需要这个妆”。时间、地点、人物、场景、衣服、天气、拍摄环境等，只有真的影响妆容判断才写。

常见问题：
- 她化完去哪？
- 见谁/做什么？
- 穿什么？
- 要待多久？
- 室内还是室外？
- 这些信息具体影响你哪一个决定？

### 拉期待

看“她有一个什么具体问题，观众想看最后怎么解决”。

常见问题：
- 她自己最在意什么？
- 这个问题具体落在哪里？
- 今天实际动哪里？
- 最后变化是否看得见？

## 新增两条成熟内容入口

### 人物/日常

适合老客、工作室一天多个客人、熟客关系、接待细节、工作状态。这里不强迫每条都出现专业诊断。

### 私教学习

适合普通人化妆私教：原来会什么 → 缺什么 → 今天学什么 → 老师怎么判断 → 学会后做到什么。

## 中心规则

一次只抓一个主要中心。其他信息可以出现，但不能抢主线。

中心不是服务前拍脑袋锁死；服务结束后根据真实发生的东西最终确认。

## 剪辑的最小原则

一句话只配能证明这句话的画面。

- 说“第一次来约妆” → 进门/沟通；
- 说“黑眼圈重” → 素颜特写；
- 说“把眼尾往上提” → 对应操作；
- 说“她开始疯狂自拍” → 自拍动作；
- 说“朋友都问是不是网红” → 只有真实反馈截图/原话才使用。

新手第一阶段先做到“话和画面对得上”，不要先追求高级剪辑。


## 一天多个客人怎么教

新手不需要先学“多线叙事”。

当天几个客人，先一个一个聊清楚；AI最后负责决定：
- 哪个讲长；
- 哪个讲短；
- 是否需要“95后化妆师开工作室的一天”这类人设开场；
- 客人之间怎么接；
- 是否需要一个轻量结尾。

具体装配规则见 `vlog-assembly.md`。
