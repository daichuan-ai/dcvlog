# Vlog制作流程｜固定保底镜头 + 真实表达采访

## 启动前置：先认识人，再聊今天

新对话第一次启动 `/dcvlog` 时，先用一次一个问题认识化妆师：哪一年、哪个城市、做多久、现在是什么工作状态/主要业务。

只认当前对话里用户主动提供的信息，不因为宿主历史记忆或旧 Skill 里有资料就跳过。用户明确说“继续上次”除外。

认识完以后先问今天一共几个客人，再逐个采访。

## 采访最后固定一步：再定前5秒

前5秒很重要，但不要提前问。先把她最熟悉的化妆、判断、动作、结果聊完，让她先有完成感。

最后固定执行 `opening-selector.md`，只保留四个方向，并按粗体编号让她选：

**1. 强画面**：工作室/场景/本人审美/动态很抓眼。  
**2. 强情绪**：互动、对话、动作的情绪浓度很高。  
**3. 强数字**：付款/尾款/充值/聊天等画面里有显眼数字。  
**4. 纯文案钩子**：前三类都弱时由AI根据已确认事实写。

每个方向只举一个例子，不绕抽象概念。最终得到“前5秒画面 + 开场字幕/旁白”再装配全文。

## 内容视角

AI先站到目标客户/普通观众那一边决定什么值得讲。专业深度够解释“为什么这样做”就停，不为了证明老师懂得多而继续堆术语。

## 核心教学顺序

新手不要同时承担“化妆、选题、文案、拍摄、剪辑”五件事。

第一阶段把制作拆成：

`服务前只定观察任务 → 按固定清单拍保底素材 → 完成真实服务 → 看着画面像聊天一样复盘 → AI逐个完成客人内容单元 → AI装配整条Vlog → 一句话配1—3个证据镜头 → 简单剪完发布`

固定的是保底素材，不是每条文案。

## 服务前：只给一个候选观察任务

不要提前写完整文案。根据已知客户信息，给一个轻量候选：

- 今天留意她为什么来；
- 今天留意她最在意什么；
- 今天留意你第一眼最想改哪里；
- 今天留意她本来最值得保留的特点。

真实服务过程中允许推翻候选中心。

## 新手保底镜头

DCVlog 当前默认学员已经按课程标准拍齐基础镜头，不把这些当作采访变量。

默认已有：
1. 客人进门/刚到店时的素颜；
2. 客人坐下；
3. 与客人沟通；
4. 素颜正面/侧面基础记录；
5. 化妆关键步骤；
6. 素颜到妆后的变化效果视频；
7. 手机给客人拍妆后照片并修图；
8. 送客；
9. 收款等常规流程。

采访时禁止再问这些有没有拍到。详细按 `standard-shot-baseline.md`。

只有前5秒需要的特殊素材——强场景、本人审美/动态、强情绪、强数字页面等——才询问当天有没有。

## 原《化妆师视频制作流程指南》的三条中心

### 找看点

看“原来是什么感觉 → 今天准备变成什么感觉”。

常见问题：
- 她原来第一眼是什么感觉？
- 是哪些具体特征让你这么判断？
- 今天准备把她往什么方向带？

### 圈人群

看“今天为什么需要这个妆”。时间、地点、人物、场景、衣服、天气、拍摄环境等，只有真的影响妆容判断才写。

常见问题：
- 她化完去哪？
- 见谁/做什么？
- 穿什么？
- 要待多久？
- 室内还是室外？
- 这些信息具体影响你哪一个决定？

### 拉期待

看“她有一个什么具体问题，观众想看最后怎么解决”。

常见问题：
- 她自己最在意什么？
- 这个问题具体落在哪里？
- 今天实际动哪里？
- 最后变化是否看得见？

## 新增两条成熟内容入口

### 人物/日常

适合老客、工作室一天多个客人、熟客关系、接待细节、工作状态。这里不强迫每条都出现专业诊断。

### 私教学习

适合普通人化妆私教：原来会什么 → 缺什么 → 今天学什么 → 老师怎么判断 → 学会后做到什么。

## 中心规则

一次只抓一个主要中心。其他信息可以出现，但不能抢主线。

中心不是服务前拍脑袋锁死；服务结束后根据真实发生的东西最终确认。

## 剪辑的最小原则

一句话只配能证明这句话的画面。

- 说“第一次来约妆” → 进门/沟通；
- 说“黑眼圈重” → 素颜特写；
- 说“把眼尾往上提” → 对应操作；
- 说“她开始疯狂自拍” → 自拍动作；
- 说“朋友都问是不是网红” → 只有真实反馈截图/原话才使用。

新手第一阶段先做到“话和画面对得上”，不要先追求高级剪辑。


## 一天多个客人怎么教

新手不需要先学“多线叙事”。

当天几个客人，先一个一个聊清楚；AI最后负责决定：
- 哪个讲长；
- 哪个讲短；
- 是否需要“95后化妆师开工作室的一天”这类人设开场；
- 客人之间怎么接；
- 是否需要一个轻量结尾。

具体装配规则见 `vlog-assembly.md`。
