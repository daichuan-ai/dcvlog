# V1.8.4｜初级化妆师的审美观察采访

用途：主线初步出现以后、判定“够写”以前执行。目标是把真实服务中已经做过的判断找出来，不让“客人要什么妆 → 眼影腮红口红 → 她很满意”直接过关。

## 一、后台保存四个信息位，不把它们当作文案四段式

1. `story_focus`：本条视频最值得讲的具体事。生日、面试等场景可以单独做主线。
2. `person_or_scene_hook`：一个能让观众记住的真实人物印象、场景氛围、服装气质、原本困扰或风格反差。**不强迫找五官缺点。**
3. `aesthetic_choice`：化妆师做出的一个真正取舍，以及为何这样决定。可以是顺着服装质感，也可以是没有继续加强眉眼、保留某个优点；不能只列产品颜色。
4. `visible_result`：化完后能在妆后画面里看见的变化、气质或效果。客户原话、表情和返图另记为 `verified_reaction`，不能用“她很满意”代替 `visible_result`。

“生日 + 粉裙 + 韩式甜妹 + 粉色眼影腮红唇色 + 她开心”**不是够写**；它只是一张信息卡。还有一项审美取舍和一项可见成片印象没找出来。

## 二、提问顺序：每轮只问一个，直接复用已经说过的答案

先问当前缺失且最有价值的一项，不机械走完所有题。

**补人物/场景印象：**

> 先不说眼影、修容。你第一眼看她本人配这身衣服，感觉更像一个什么样的女孩？

如果只会回答“黑眼圈、鼻基底、中庭”，接住专业观察，再把问题改成普通人的结果感受：

> 你说的这个地方，会让她整个脸看着更累、更凶、更学生气，还是别的感觉？

不要将选项当成已经证实的事实。用户说“都不是”就回到现场或跳过这项，不能逼选。

**补审美取舍：**

> 今天这个场景和她本人放在一起，你最不想把她化成哪种感觉？

等她回答以后，**下一轮**再追：

> 那你今天实际做的哪个决定，是为了避开这种感觉？

如果用户已经说出“怕化浓显老 / 想像小时候一样甜 / 不想抢风头”，不再重复问，直接记录它影响的真实决定。

**补结果画面（优先级高于客人反馈）：**

> 妆化完你自己第一眼看她，和刚来时比，整个人最明显变成什么感觉？先别说她满不满意。

若还是“好看/高级/很适合”，追一个可感知的细节：眼神、轮廓、气质、神态、服装的整体关系或成片里真实突出的画面。接受“说不上来”。

如果宿主支持图片并且用户愿意，可以说“有妆后照片发一张，我看真实画面帮你找词”；不要把照片当成必交作业。看不到照片时不得冒充已看见。

**补真实反馈（可选）：**

> 她有没有一句原话，或者你实际看到她做了什么？没有就不写反应。

不默认“照镜子很开心”“疯狂自拍”“说这是人生妆”。

## 三、卡壳分支：帮助选择，不替代事实

- 学员说不出审美词时，给2—4个**基于已知素材的候选感受**并明确“哪一种接近？都不是也行”。候选不等于已确认，未经选择不得入稿。
- 连续两次回答“不知道/都不是”，停止追同一问题。可问是否看成片照片；用户不愿提供就保留缺口。
- 如果只是不会表达，但已经确认“整体更灵动/更有仪式感”，可以帮她找到普通人能听懂的自然句子；不得补脸型、妆容步骤、客户反应等新事实。
- 不把初学者带进长时间专业面诊。每位客人通常只补1—3个缺口问题，多客人保持主次递减。

## 四、够写闸门

满足以下条件才进入开场/写稿：

- 已有一个明确且可讲的 `story_focus`；
- `aesthetic_choice` 的因果真实成立（不是“粉裙子所以全套粉色”这样的机械配色清单）；
- `visible_result` 至少有一个用户确认的可见变化/整体印象，或用户提供的妆后图片里实际可辨认的事实；
- 没把猜测写成事实，客户反馈有出处才用。

如果结果实在无法描述：允许用户选择“先按已知信息写克制版，成片处让真实妆后画面说话”。此时不得捏造结果形容或客户反应；在交稿旁边简短标记“结果画面描述缺素材，等待妆后图校准”，不要伪称完整达标。

## 五、完整客人与多客人

单个客人建立一条独立的审美取舍。多客人第1位最完整，第2位挑与前面不同的一点，第3位以后只保留真正独特的判断和画面；不要求每位都重复相同采访题，也不因多客人减少已确定的视频人数。
