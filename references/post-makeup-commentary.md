# V1.8.6｜妆后作品解读：第1位必讲，后面递减

## 目标与默认画面

课程视频默认每位客人都有：到店/素颜、化妆过程、妆后照片和妆后视频。**不能把作品段写成一句“很满意”就过去**。对于单客视频或多客中的第1位，最终结构始终给照片/视频留下作品展示节点，旁白在这里让观众知道**这套妆好在哪种方向、和这个人有什么关系**。

后台装配顺序：`开场 → 客人到店与素颜反应 → 一项关键化妆判断及过程 → 【作品照片/视频+审美旁白1—2句】 → 有证据再补反馈 → 下一位`。这是画面节奏，不是朗读五个小标题；不要求缺陷诊断。

**第1位作品旁白必写；第2位简写结果；第3/4位可以一句真实需求/风格带到作品画面。**例如第3位“她今天约会，想清爽一点，我给她做了淡淡的白开水妆。（妆后作品展示）”就能停，不强求第3位浪漫比喻。实际妆容风格必须来自学员输入。

## 50/50辅助表达＝用户提供事实，AI负责让人看见

“各一半”不是允许AI编一半故事。把素材分三层：

1. **F｜真实锚点**：学员说过的用途/顾虑/服装/人物观察/妆容风格/真实动作、学员确认的结果、AI实际看过的妆后照片。F只能来源于本次客人。
2. **E｜AI表达加工**：在F基础上的审美解释、主观感受、节奏、视觉比喻、轻度情绪。E可以由AI主动拟，但必须对应F，不新增眼睛尺寸、脸部结构变化、客人心理或真实行为。
3. **X｜未经证实的新事实**：假造“她自己都认不出”“现场疯狂自拍”“整个人小了一圈”“拍照更出片”“眼睛立刻放大”“她第一次被夸”。X绝不入稿。

只确认了妆容方向，没有看到成片/学员没确认实际效果时，允许用**设计意图型作品旁白**：“我想要的不是妆很浓，而是……”“这个妆的重点放在……，让镜头落到……”；**不能写“妆后果然/最后真的/明显变得/站在人群中……”冒充已发生的视觉效果**。这段意图旁白可以铺在真实照片视频上，作为可用的有根据表达；若要宣告结果真实成立，需要学员确认或AI真的看过图片。

## 小白不会描述时：一次只问一个问题

学员：“很好看 / 很满意 / 我说不出 / 就那个感觉。”

不要重复问“到底哪里好看”；先接住已经掌握的F，主动把审美翻译成**2—3个不同角度的短候选**，让她直接选或否定：

> 我来帮你找作品那两句话。按你说的“粉裙、淡粉妆、不想成熟”，更接近哪个感觉？
>
> **1. 轻轻柔柔的甜，不像浓妆那样抢眼**
>
> **2. 裙子和妆容放在一起很统一，有点奶油粉的感觉**
>
> **3. 重点是整个人有仪式感，但还保留她原来的清爽**
>
> **4. 都不像，我再说一点**

以上是假设的“**学员确认过粉裙、淡粉、不想成熟**”才可提出的候选，**不是通用事实库**。即使选了1，仍不能写“眼睛变大、面中缩短”这种额外事实。

只有纯文本时，首轮先问学员妆后最能看出的**一个对比或感觉**，再给候选；已经知道用户很难表达时直接给候选，省去抽象追问。用户选中候选后，可把该审美解读纳入结果描述；未选择不能把候选偷偷当事实。若可以看到用户发来的真实照片，优先从脸、发型、服装与成片气质中直接寻找可见锚点，仍区别“我的视觉感受”和“客户说的话”。

## 可选的审美语言，不是套词库

按**已证实的锚点**选择合适的表达层：

- **视觉层**：眼神、眉眼力度、轮廓干净程度、肤质通透度、唇色和服装呼应、卷发与脸型的关系。
- **气质层**：甜但不幼、冷但不凶、利落但不强势、温柔但不寡淡、像没费力却很精致。
- **形象/比喻层**：眼睛形态确实像小兔子才可以说小兔感；暖棕衣服和柔软发型确实成立才说像秋天阳光；不强行“千金/爱豆/公主/电影女主”。
- **情绪层**：化妆师本人看作品的感受可以表达为“我更喜欢她这样轻一点的状态”，但不得虚构客人被感动、重获自信或大家都夸。

优先用**一个准确意象**，不要堆“浪漫、电影感、贵气、温柔、高级、氛围感”。旁白是帮观众理解成片，不是给画面打广告。

## 反例与可播对照

**只有这些真实事实：**“生日、粉色裙子、粉调眼影/腮红/唇色；没有亲眼描述妆后具体变化。”

不合格：“画完像个粉粉嫩嫩的小公主，客人看得眼睛都亮了，整个人自信得不行。”（新事实+滥比喻）

可用的**意图型**作品旁白：“这次我没想把生日妆画得很重，眼睛、脸颊和唇色都顺着那条粉裙子走。我想要的是一整套轻轻柔柔的生日氛围。”（事实+设计审美，无妆后结果断言）

**若学员进一步确认**“妆后觉得眼神柔和，原本那件衣服穿着有点稚气，现在更像温柔的小姑娘”，可写：“完妆之后，她还是那种甜甜的感觉，但眼神柔了，粉裙子也不再像学生穿搭，反倒有点软软的少女感。”（用户确认的结果+AI提炼）

成熟案例03的小兔子比喻来自真实下垂眼；案例06的疏离感来自长相英气+低饱和冷调；案例17巧克力意象来自真实肤色和人物个性。**学表达生成的方法，不移植这些案例的具体事实。**

## 装配闸门

第1位（或单客）必须在“妆后照片与视频展示”这一节点有至少1句**非泛夸**的作品解读，优先1—2句；真实结果可确证则写结果，不能确证时用明确的意图型表达并在稿外提示“未确认具体妆后变化”，不得装作实际结果。若此人缺关键审美取舍/结果，继续按主采访的 `NEED_ASK / READY / LIMITED_DRAFT` 做放行处理。

第2位只留人物差异+实际决定，有真实结果可短点一句；第3/4位允许靠照片视频，自然读出一个真实需求或风格就够。**不以“后位没有结果描述”否决整条多客稿。**
