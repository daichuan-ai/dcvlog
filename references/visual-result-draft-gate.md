# V1.8.6｜首位作品画面、逐句证据与反模板闸门

首位或单客写稿前须从 `aesthetic-interview.md` 得到 `READY`；用户同意缺口版时只能交 `LIMITED_DRAFT`。第2位以后按 `LIGHT_READY` 轻量标准放行。首位内部核对：“今天最值得讲的是___；我根据她的___，选择了___；在妆后照片/视频中，观众应该怎样理解这个设计？”后一句须区分**实际看见**与**设计意图**。

## 1. 成熟案例的学习单位

- 同类型优先读 `corpus/batch-003-raw-20261016/selection-guide.md`，再读 `cases.md` 中对应的原文。
- 19条是原样转写：第01—02条为片段，第11条很短，其余以多客人工作日为主，不能拿一个完整“三客人Vlog”的总字数压单客人稿。
- 只对照原文中**对应某一位客人的段落**，学习人物视角、转折、句子职责、成片画面、情绪和停止位置；单客长度比较单客段，多客比较同客人数的装配。**案例12第三位**以约会/白裙/面中留白支撑不化浓妆；**案例18第三位**以拍照需求/圆润唇形解释处理，但结果证据不足，不能视为完美收尾；**案例19第一位**以拍照/之前显老/有依据的客户反应形成故事。真实样本自身的缺口不能照搬。
- 不照搬博主的“宝宝”“超级美”“一起来看”、个人品牌、想象反应、广告口播、误识别错字。原文的错字不需要复制进新稿。

## 2. 结果画面不是反馈

第1位在完妆**照片和视频**出现时必须挑一项有真实素材支持的方向，写1—2句作品解读；AI可把用户的专业动作翻译成浪漫、类比、审美感受，但不得编外部事件。详见 `post-makeup-commentary.md`。不是每条都要诗意比喻：

- **可见变化**：原本偏学生气、完妆显得更利落；眼神更明亮；整体轮廓更柔等——只有已确认才写。
- **人物气质**：从偏甜到清冷，或保留英气又多一点柔和；与真实脸、服装及妆后状态对应。
- **形象比喻**：如原文小兔子、巧克力女孩，是从真实可辨认的特点自然联想出来的。无依据时不要强加公主、电影女主或仙女。
- **场景的最终状态**：生日聚会/领证/面试的氛围是否落实；不要把未经证实的第三方观感写成事实。

客户真实原话、自拍、返图、笑容是**可选的第二证据**。它们不能独自顶替首位作品解读。没有客户反应就让成片画面停，不假造“看镜子可开心了”。

**拍摄需求 ≠ 拍摄效果已验证。**“为了上镜，我加强了轮廓”可能是确定的服务动作；“她出门那个状态，拍照妥妥够用”则是未经证实的结果，不允许以旁白口气补进稿。

## 3. 先诊断素材，再写结构

后台先锁一条主线及每位客人可支持的“人物差别”。从真实素材中选最强切入：

1. **人物先行**：独特长相、原本气质、困扰或矛盾最强；
2. **场景先行**：用途本身有具体且真实的取舍；
3. **客户原话先行**：一句话揭示不想重妆、怕显老、想试新风格；
4. **变化先行**：妆前与妆后视觉反差最清楚。

不要每篇固定“X岁化妆师在Y城市开工作室 → 客人今天过生日 → 眼影腮红口红 → 她照镜子很开心 → 我最懂普通人，拜拜”。相同信息按不同的叙事价值取舍，身份开头/人设尾巴有素材和用户意愿才用。

场景型**可以不分析五官**。但“粉裙配粉妆”“黑裙配烟熏”这种仅靠配色的说明，不自动等于审美判断；至少需要用户确认的场景氛围、取舍理由、人物特点或可见结果中的真实关系。

## 4. 正式成稿的质量检测（写在后台，不向学员背清单）

任何一项失败就定向重写或补问，不用增加花哨修辞掩盖：

1. **主线**：一个客人真正讲的一件事是什么？全文是否仍围绕它？
2. **审美决定**：有没有解释一个真实“为什么这样，不那样”，而不是罗列颜色/步骤？
3. **首位作品节点**：妆后照片+视频处是否有1—2句具体、基于事实的审美旁白？“高级/好看/适合/满意/效果对了”单独出现不合格；后位可由真实需求引入直接出片。
4. **真实性**：形象联想是否有真实特征锚点？客户原话、照镜子、自拍和第三方反馈是否真的发生？每个动作是否确实被当事人描述过？
5. **旁白而非教程**：只保留影响主线的1—2个关键技术动作，不按底妆→眼影→腮红→口红念流程。
6. **反模板**：与其他客人只能换“城市、裙子颜色、妆容名和口红色”就通用吗？如果能，说明人物辨识度为零，回到采访补一项。
7. **结果停止**：结果成立后自然停，不加课堂总结、哲理升华或强行高赞夸赞。
8. **对照原文**：至少参照2个相近的真实客户段落；长度是软校准，事实和主线比凑字数重要。

如果只是语气微调不能修复问题，必须回到人物判断和结果素材，不能用“自然日常 + 沉稳专业”把模板再润色一次。

## 5. 逐句证据检查｜事实、转述、假设分清楚

写稿后在后台把涉及人物、动作、观察、客户言语和结果的每个句子，对照学员回答；一旦找不到原始依据，就删去或回问，不能因为句子读起来更生动而保留。

| 学员确实说了 | 可以写 | 禁止写 |
|---|---|---|
| “可能第一次花钱找外面的化妆师吧” | “她说自己可能是第一次找外面的化妆师”或不写第一次 | “这是她第一次付费化妆” |
| “给我看了图片，先从模仿一个开始” | “她拿了张参考图，我们先对齐大概方向” | “她指着手机说：‘我就要这种’” |
| “上镜要轮廓感，妆透一点，网感” | “我把轮廓做得更明确，底妆保持通透”（动作确实做过才用） | “她拍照妥妥够用”“整个人高级了” |
| “没有客人反馈/返图” | 不写反馈，继续询问妆后观察 | “她对着镜子很满意、疯狂自拍” |

**直接引号只能放学员确实记得的客人原话。**学员转述、概括、揣测都用间接叙述；不能制造“指着说/掏手机/当场害怕”等具体镜头。课程默认有“坐下/沟通/妆后”的标准镜头，不代表实际拍到翻参考图或特定对白。

**风格选择不能验证成效。**若没有真实妆后印象，允许首位作品段用已确定妆容的**设计意图型审美句**（例如“我想要的不是浓，而是和裙子同一套轻柔感觉”），另行标注实际结果缺口；不能说“妆后刚好”“效果对了”“很适合她”等伪结果。

## 6. 禁止通过的反例

**失败A：** 生日、卡其毛领、贵气千金、金棕眼影/同色腮红/唇釉、客人看镜子开心。

**失败B：** 生日、粉色小裙、韩系甜妹、粉色眼影/腮红/唇色、客人看镜子开心。

二者只替换了衣服和化妆品关键词，无法让人看到不同的人物。不能因为“五段齐全”就交稿。应分别追问一个真实审美判断、一个成片效果；若确实没有，则输出诚实的克制版并提示缺口。

**失败C：** 教师岗面试客人说“别太浓”，AI把故事写成“转色遮瑕→粉底→低饱和眉眼→口红”的化妆建议，再以“舒服放心”结尾。因服务教程化、人物不可见而不合格。

**失败D｜2026-10-18 小白实测复盘：**约会、上镜、可能第一次付费找外部化妆师、带参考图，学员说“沟通一下、轮廓感、通透、网感”，并明确**没有反馈**。AI在没有追到个人审美取舍、没有任何妆后变化信息时，转问满意度、选择开场人设，再写“指着说：我要这种”“拍照妥妥够用”，最后声称“事实一个字没动”。这同时违反**采访门槛、事实确定度、结果画面**三项，必须拦截；改调皮语气不能补救。
