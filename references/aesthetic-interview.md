# V1.8.6｜首位审美采访：事实锚点+AI辅助表达

适用：单客或多客**首位客人**主线初步清楚后，在客户满意、开头、人设、写稿之前执行。第2位轻采访，第3/4位可直接带作品，不强制跑完五事实位；详见 `post-makeup-commentary.md`。一次只问一个问题。

## 一、后台建立五项事实卡

| 字段 | 合格内容 | 不合格替代物 |
|---|---|---|
| `story_focus` | 今天为什么来、最值得讲的真实事件或矛盾 | “今天化了一个漂亮妆” |
| `distinctive_anchor` | 此人真实特点、服装与场景的独特关系、真实顾虑或反差；场景充分时不强迫找脸的缺点 | “美女、网感、很适合” |
| `aesthetic_tradeoff` | **这位客人**为什么要这么画、没有照搬什么、减弱/保留什么，以及具体依据 | “参考图先沟通好”“服务很耐心”“上镜需要轮廓感” |
| `actual_choice` | 今天真实采用的一项决定或动作，能和上述依据相连 | “打底妆、画眼影、腮红、口红”步骤表 |
| `visible_result` | 学员确认的妆后变化、AI实际看过图片后有锚点的观感，或学员认可的基于已知事实的作品审美描述；未看到/未确认时须保留“设计意图”语态 | “满意、很好看、够上镜、客户喜欢” |

客户真实原话、笑容、自拍、返图另存 `verified_reaction`，**不是必要字段，也不能替代 `visible_result`**。即使没有妆后反馈也不影响继续采访完妆画面。

同时记录证据状态：`确认的事实`、`AI可见图片观察`、`学员认可的审美表达`、`未经确认候选`、`未提供`。**审美语言可以由AI写，新的可检验事实不可以由AI补**；未经确认的候选不能冒充真实结果。

## 二、按照缺口问，不按一张固定问卷

优先顺序：**先找到和本人相关的设计取舍 → 再问最终可见变化 → 最后才考虑客户反应**。对已经回答过的内容直接复用，不重复。

### 学员只说“轮廓感、通透感、网感”

这是风格词与一般拍摄常识，**没有**说出此人的审美取舍。不要回“对，拍照不吃妆才叫上镜”并结束采访。

若客人带参考图，问：

> 你看了她本人和参考图之后，有哪一点最后没有直接照着画？

如果答出实际差异，**下一轮**才问“你为什么没照搬那一点？”；不可一口气问两个问题。

若没有参考图，问：

> 她今天这个人和场合放在一起，你最不想把她化成哪种感觉？

等学员回答，**下一轮**再问实际动作：

> 那为了避开这个感觉，你今天实际动了哪一处？

“照着参考图画”“先问清能接受多浓”“耐心沟通”是**服务流程判断**，可以用在故事里，但不能自动算“审美取舍”。要补“看到这个人以后为什么保留/调整/舍弃参考图的一部分”。如果确实完全照图，接受真实回答“没有改”，再找场景限制或客户更在意的取舍；不能逼学员编一个不同。

### 学员只讲“黑眼圈、中庭、眼尾、底妆”

接受技术词，再转成普通人的观感：

> 你说的这个特点，在她本人身上，会让她看起来更疲惫、更学生气，还是别的感觉？都不是也可以。

候选必须来自已有信息，并等对方确认；不能自动诊断脸型或缺点。

### 缺妆后画面（不可跳过）

> 化完你第一眼看她，和刚坐下比，整个人最明显变了什么？先不说好不好看，也不用说客人满不满意。

如果回答“好看”“高级”“适合”“拍照够用”“不知道”，**不要只重复追问**。立即读取 `post-makeup-commentary.md`，基于已知穿搭/风格/实际动作提出2—3个不同审美角度让她选择；若素材很少，先问一个可感知的点：

> 我们先不夸妆。是眼神/轮廓更有精神了，还是衣服和整个人的气质更搭了？都不是就说不是。

这些只是候选，不是事实。若已有脸或穿搭信息，候选应换成更贴近那个人的2—3种可能观察。学员选中后可由AI写她认可的主观审美表达，不能凭选择凭空新增“鼻子更高/眼睛更大”等客观变化。

如果宿主支持图片且学员愿意，可以请她发妆后照片一起看。**标准镜头默认拍过，不等于AI已经看过妆后画面**。

### 有真实客户反馈时

确认是谁说的、记得多准确。只能复述大意时用间接转述，不造引号内原话。**反馈在妆后画面之后，不能靠它单独完成故事。**

## 三、两次卡壳后的诚实退路

对同一个核心缺口最多两次救援。连续“不知道/都不是/没注意”后不要第三次猜或强迫专业面诊：

1. 可提出发妆后照片帮助观察的选择，不强制；**默认作品照片和视频已经拍好**，不是问是否存在。
2. 若仍缺真实取舍或可见结果，**先交给学员一条基于已知事实的设计意图型作品句供确认**，仍不能确认时才问：

   > 妆后的具体变化我们还没确认。我可以先用你确定的妆容和衣服写一条作品解读，不编客人的反应；要不要先给你一版能录音的**克制试稿**？

3. **只有用户明确同意**，才标记 `LIMITED_DRAFT`；在稿外标“还缺：设计依据/妆后画面”，不编也不假装达标。
4. 不能自行宣布“正文已经有了”然后跳到开头或结尾；若用户不愿试稿，就暂停等待新观察。

## 四、唯一放行条件（后台逐项检查）

`READY` 必须满足：

- `story_focus` 已明确；
- 有一个本人的 `distinctive_anchor`（场景与服装关系也行，不强制五官缺点）；
- `aesthetic_tradeoff` 说明为什么不照常做/为什么保留或改变，**沟通流程不能替代**；
- `actual_choice` 至少一项真实行动，与取舍相连；
- 作品展示有经过核对的画面描述；**设计意图型不能伪装成看到的结果**，仍无结果则需同意 `LIMITED_DRAFT`；
- 所有关键事实保留确定度，不编客户原话或场景动作。

**任一不满足：`NEED_ASK`（继续补一问）或经用户明确许可的 `LIMITED_DRAFT`，不能宣告 `READY`。**

多客人：首位按上述检查，第二位达到 `LIGHT_READY`（一个新点+实际决定），第三/四位达到 `LIGHT_READY`（真实需求/场景+实际妆容）即可；后位缺完妆描述可以直接展示拍过的作品，不能编评价。

## 五、真实测试回归拦截点

若输入链为：

“约会、想上镜 → 可能第一次找外面付费化妆 → 她拿参考图 → 我先沟通 → 轮廓清楚、底妆通透、偏网感 → 没返图/没反应”。

**不得**在“轮廓、通透、网感”后转问满意度，也不得宣布正文完整。应先追“参考图与本人之间的设计取舍”，再追“妆后实际看到的变化”。若两次卡壳，只能经同意给 `LIMITED_DRAFT`，绝不能写“拍照妥妥够用”。
