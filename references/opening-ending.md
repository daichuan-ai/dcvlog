# E0.6 覆盖提示

本文件的强画面和结尾旧示例若与 `e06-writing-refinement.md` 冲突，以 E0.6 为准：强画面默认身份短旁白；结尾不强制人设口号。

# E0.5｜开场选择的最高优先级补充（覆盖下文 E0.4 强画面矛盾规则）

**课堂四选一照旧；不要新增第五类，也不要把四类都写成身份口播。**

**1. 强画面＝有辨识度的本人/工作环境镜头＋一句浓缩的人物身份型 Vlog 开场。** 选了1后，使用此前已知的代际、城市、工作形式、差异化特点和日常约妆内容，挑最有辨识度的2—4项组合成**一条约3—4秒能自然念完的口播**。不需要逐项填满，也不要求华丽工作室。比如“00后化妆师，在绵阳创业，给妹妹约妆的一天”；“80后宝妈在家创业，给普通女孩化妆的一天”。仅为结构示例，绝不能把示例身份冒充学员事实。**禁止再问“纯画面还是配旁白”“有哪几类素材”“要不要加钩子”**；此前已确认本人和工作场景，就直接给一句可用开场让学员确认，必要时可微调。此处所谓“强”是画面与身份共同让观众迅速认识主角，不是悬念营销或单纯描述画面。开场口播3—4秒为目标，以试读顺口为准，不机械规定汉字数。

**2. 强情绪＝确实录到的现场原声**（笑声、互动、惊讶等），不编台词、不强加身份旁白。**3. 强数字＝确实拍到、可公开展示且引人好奇的数字证据**（付款/充值等），避免泄露支付隐私；普通客人数不自动算强数字。**4. 纯文案＝从今天客人的第一印象、用途、需求、特点切入**，不默认套身份介绍。选2/3而无证据时说明原因并请学员换方向；选4则主动写一句约3—4秒短句。

**最终交付：**已确认的开场必须出现在连续旁白最前；方向2/3若采用原声或数字镜头，可在稿首用清晰的镜头/原声标注，不要凭空补配音。学员的选择确认不可推断未说明的素材都存在。

# 前5秒 + 结尾｜主角型开场、客人直入、现场原声、人设尾巴

<!-- E0.4 旧版强画面规则已由顶部 E0.5 规则取代，避免同时存在纯画面/身份口播的相反要求。 -->

## E0.3｜开场选择是重点教学节点

保留原有**四方向完整选择菜单**，不要因为“没有特殊素材默认客人直入”就直接替学员跳过课堂熟悉的选择。四方向按数字独立成行：

**1. 强画面｜本人/工作室有辨识度的镜头**

**2. 强情绪｜当天确实录到的现场原声**

**3. 强数字｜有真实画面证据的客人数/付款等**

**4. 纯文案钩子｜从客人到店、需求或妆前画面进入**

用一句简短提示帮助学员回忆课堂讲过的开头方法，再问一个问题：`❓ **你这条视频更想用哪一种开头？回复1—4；不确定我可以按现有素材帮你选。**`。允许学员选多个候选再核对素材；不得因为学员选择了没有真实素材的2/3就编原声或数字。此处可以比一般采访多花一点解释篇幅，仍然不要连续提出多个问题。

确认选定开场后保存**确切开场文字**与镜头来源；最终连续旁白必须含这一开场。结尾同理保存已确认的具体文字或自然停止方式，参见 `assembly-check-e03.md`。

旧版“只有特殊素材才问”“默认方向4直接跳过菜单”的简化策略在 E0.3 **不适用于首次开场选择**；如果学员此前已明确指定开场方向则直接沿用，不重复问。

## 一、前5秒一定后置

主体通过 `aesthetic-interview.md` 的 `READY` 闸门后才做；缺取舍或可见妆后画面时，**禁止**说“正文已经有了”。若有强素材但学员没主动选择，可给一次四方向菜单：

> 好，正文已经有了。最后只看前几秒怎么开。我给你四个方向，你直接选数字就行。

固定四类，不能新增第五类：

**1. 强画面｜化妆师主角型Vlog开头**  
工作室漂亮、远景/中景/特写完整，或者你本人有高审美自拍、穿搭、工作状态、动作等能先建立“这个化妆师是谁”的画面。

**2. 强情绪｜真实现场原声**  
客人真实笑声、尖叫、惊讶、情绪明显的对话或互动。

**3. 强数字｜有证据的数字**  
付款、尾款、充值、客人数等当天确实有截图、页面、录屏或现场画面。

**4. 纯文案钩子｜直接从客人进入**  
没有主角型强画面时，从客人坐下/脸部画面开始，第一句直接讲她今天要干什么、想要什么、有什么麻烦或最值得看的变化。

> 你今天更接近哪一个？直接回数字就行，几个都有也可以说。

没有情绪原声、强数字或化妆师主角型画面时，**默认直接用方向4客人直入型，给出一条可靠的开场即可**；用户愿意探索才展示四方向菜单。命中明确方向后不继续追问一长串，最多给2个成品开场让用户确认。不能强迫学员再做一轮与故事无关的选择题。

## 二、方向1｜强画面不是“随便一个漂亮镜头”，而是化妆师主角型开场

只有出现下面这类素材，才优先走1：

- 漂亮/有辨识度的工作室远景、中景、特写；
- 化妆师本人高审美自拍、出镜、穿搭、妆面、动作；
- 能让观众先认识“这个化妆师/这家工作室”的工作状态；
- 画面本身足够撑住前2—4秒。

命中后，旁白不是描述画面，而是用前面已经确认的资料快速建立主角身份。优先组合：

`代际/年龄 + 城市 + 工作/创业状态 + 最有记忆点的真实特点/目标 + 一天Vlog`

例如逻辑：

> 00后化妆师，在绵阳开个人工作室，专门给普通女生找最适合自己的妆，今天继续营业。

这只是机制示意。城市、年龄、业务、特点必须来自用户真实信息。

V1.8.4 反模板：**不要每条默认使用“年龄/从业年数 + 城市 + 小工作室”作为第一句**。只有用户选了主角型强画面、人物身份确实有记忆点时才这样开；若本次客人原话、人物反差或用途更强，按方向4直接讲她。即使身份信息真实，也不代表每条都值得放。

### 方向1后面的标准进入顺序

`工作室/本人强画面 → 客人开门到店 → 介绍今天客人 → 沟通画面 → 提出客人的用途/真实需求/问题/变化`

不要一上来就剧透最终妆后结果。

### 强表达规则

开场要有记忆点，可减少无信息价值的口头停顿；**表示事实不确定的“可能、大概、她猜”绝不可删去，除非整个不确定事实不写**。在学员明确确认且本人真愿意表达时可考虑：

`超 / 超级 / 最 / 特别 / 很 / 最会 / 最懂 / 最稳 / 最细 / 最负责 / 厉害`

但“表达要强，事实要真”。不得无依据写“全城第一、行业唯一、最厉害”等可核验事实；**“最会/最懂”也不是通用默认人设**。

## 三、方向2｜强情绪必须是原声，不能用旁白冒充

强情绪开场的核心不是AI写一句“情绪很浓”的文案，而是**当天真实录到的声音**。

可用：
- 客人突然笑得特别开心；
- “哇，这真的是我吗？”之类真实原话；
- 领证/生日/见家长等现场里情绪很明显的对话；
- 惊讶、尖叫、打趣、笑声、强互动。

最终输出必须明确标：

> （视频原声）“……”

或

> （现场原声）“……”

没有真实原声，不走方向2。

---

## 四、方向3｜强数字必须有画面证据

数字有意思还不够，必须能拍给观众看。

可用：付款、尾款、充值、客人数、复购次数等，但要有当天真实截图/页面/录屏/现场画面。

没有可展示证据就换方向，不把“听起来厉害”的数字写成开场。

---

## 五、方向4｜客人直入型，不强行让化妆师先当主角

如果没有方向1那类强工作室/本人画面，直接从客人坐下开始完全成立。

第一画面让观众看到客人的脸，然后第一句直接进入这次工作：

- 她今天去干什么；
- 她自己想要什么；
- 她最在意什么；
- 今天有什么变化值得看。

AI基于已经确认的主线最多给2个短钩子，不额外编事实。“给我看参考图”不可被写成“她指着手机说：我就要这种”。录到当事人翻图动作也需确认；标准沟通镜头默认存在，不表示特定翻图片段存在。

---

# 六、结尾｜E0.6 自然收尾

执行 `e06-writing-refinement.md` 第5节。只在确有具体且可感知的个人特点、学员愿意表达时考虑一句自然的人设表达；普通工作原则不当卖点，不自夸，不强迫“人设尾巴”。可以直接“今天就到这，拜拜”，也可在作品画面自然结束。学员否定候选就舍弃，不继续给同义词二选一。
