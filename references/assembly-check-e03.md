# E0.3｜连续旁白装配与交付核验

**硬要求：最终交付以一份完整、连续、可直接配音的旁白为核心。**

## 装配顺序
1. 在内部保存 `opening_selected`：学员选定的开场方式、可用素材、对应的**确切开场文字**（或明确标注的现场原声／纯画面开场）。
2. 保存每位视频客人的正文段落，客人数必须与 `video_client_total` 一致。
3. 保存 `ending_selected`：经语言自然度检查的3—4秒结尾，或学员确认的自然画面收束（无须强写一句口号）。
4. **按 `开场 → 所有视频客人正文 → 结尾` 装配同一份《完整连续旁白》。** 已确认的开场不得只留在单独的“前5秒怎么开”栏目里。现场原声用独立提示行标明其为音轨内容，仍须出现在完整装配中。
5. 核验装配稿首句是否等于已选开场的旁白首句，末段是否与已选结尾一致；若不一致，**内部修复后再交付**，不要让学员自己拼接。

## 候选语言质量检查
- 开场和结尾**先写出成熟、自然、能读出口的候选**，再让学员选择。学员选中候选并不代表 AI 可以跳过质量检查。
- 结尾可以非常短，例如简单的“今天就到这，拜拜”；不要把人人都会做的基础工作硬包装成人设口号（如“我是会按场合定妆的化妆师”）。
- 不强迫每篇都有自我介绍、升华或观点。保留原版结尾选择权。

## 默认交付顺序
1. **完整连续旁白**：放最前面、单独成块，方便直接复制配音；开场、主体、结尾全部包含。
2. **画面怎么对**：仅列实际有必要提示的镜头/原声/结果展示位置；避免逐句重复旁白。
3. **前5秒选择与主线**：简要注明；已在旁白中体现，不再另给一份不一致的开场稿。
4. **这次练会的一件事**：仅学员要求、教学复盘场景或确有帮助时才显示；默认不占据交付正文。

## 发布前内部核验（不要全部展示给学员）
- 已确认开场 = 连续旁白开头；若开场是现场原声或纯画面，须在连续稿开头标注相应镜头/音轨，不能凭空添加口播。
- 连续稿包含每位要出镜的客人，顺序正确。
- 有自然的妆后画面落点，不虚构妆效/评价/数字。
- 结尾已确认或明确自然停，不重复、不断裂。
- 参考案例的结构和叙述密度已实际迁移到文字，不只是口头报案例编号。
- 最终稿里没有交互用 `❓`、`✅`、选择题或教学分析文字。

## E0.4 开场专项核验
- 按选定的1—4方向核验：强画面可纯镜头，强情绪用真实原声，强数字须真实且可展示，纯文案从客人事实切入。
- 有口播的开场钩子须自然试读约3—4秒；无口播开场不强行添加身份句。
- 完整连续稿第一项与已确认开场的**形式和内容**一致，不仅核对文字。
