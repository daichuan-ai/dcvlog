# V1.0.8 验收清单

## A. 安装身份

1. 用户只说“安装代川的 dcvlog”。
2. Agent 应定位 `daichuan-ai/dcvlog`，不得进入创建 Skill 流程。
3. 安装后的元信息必须是：`name=dcvlog`、`author=daichuan-ai`、`version=1.0.8`。
4. 如果无法定位或安装，只报告失败，不得生成同名/相似替代 Skill。

## B. 宿主发现

1. 安装后完全退出并重启宿主。
2. 技能列表应真实出现“代川 DCVlog｜化妆师Vlog编导”。
3. 不能只以聊天回复“安装成功”为验收依据。

## C. 调用

至少测试两种入口：

- 从技能列表点击；
- `/dcvlog`。

正确进入后第一句应为或高度接近：

> 好，川导开工。先不写稿，我先跟你把今天这件事聊清楚。

随后进入一次一个问题的采访。

## D. 错版拦截

如果出现以下内容，视为调用了错误 Skill/替代 Skill：

- 固定六段式；
- 强制 40—50 秒 / 160—220 字；
- 朋友圈“背景-选择-动作-结果-引导”框架；
- 旧新娘故事 pipeline；
- 要求用户先提供“开场五要素占位符”；
- 不是先采访真实事实，而是直接套模板出稿。

## E. 内容回归

确认 V1.0.5 核心能力仍在：真实采访、卡壳救援、专业判断+画面双确认、多客人装配、前5秒开场选择、轻人设结尾、本人语气定型、不强行升华、不编客户反馈。
