# V1.1.0 实机验收清单

## 1. 安装真实性

- 唯一来源：`https://github.com/daichuan-ai/dcvlog`。
- 元信息：`name=dcvlog`、`author=daichuan-ai`、`version=1.1.0`。
- 找不到仓库时不得创建同名/相似替代 Skill。

## 2. 显式调用

新建对话输入 `/dcvlog`。

允许技能菜单暂时不可见；只要宿主能定位真实 `dcvlog` 安装目录并读取其 SKILL.md，即可继续测试。

## 3. 首次人物认识回归测试

全新对话仅输入 `/dcvlog`。正确第一句应自然接近：

> 好，那咱们开始。我先认识一下你。你是哪一年的？

错误：
- “好，川导开工”；
- 直接问“今天这个客人来干嘛”；
- 因宿主历史记忆知道用户资料而跳过人物认识。

人物认识必须一次一个问题：年份/年龄段 → 城市 → 从业时间 → 工作状态/主要业务。

## 4. 当天容量测试

人物认识后先确认今天一共几个客人，再进入单个客人，不默认一个客人就是整条视频。

## 5. 卡壳测试

连续输入“不知道”“说不出来”“你来定吧”。Skill 应停止新增问题，给成熟表达参考；用户选中后再确认真实意思和对应画面。不得直接编专业结论。

## 6. 内容回归

必须保留：

- 目标客户视角；
- 一次一个问题、聊天式陪跑；
- 事实不等于素材；
- 专业判断 + 画面双确认；
- 多客人统一装配；
- 前5秒真实素材选择；
- 可选人设收口，不强行升华；
- 真人语料保护；
- 最后本人语气定型；
- 最终可直接录音版。

## 7. 错版拦截

出现以下任一，视为调用了错误/替代 Skill：固定六段式、强制40—50秒/160—220字、朋友圈“背景-选择-动作-结果-引导”、旧新娘故事 pipeline、直接模板出稿而不采访。
