# V1.1.5 实机验收清单

## 1. 安装真实性

- 唯一来源：`https://github.com/daichuan-ai/dcvlog`。
- 元信息：`name=dcvlog`、`author=daichuan-ai`、`version=1.1.5`。
- 找不到仓库时不得创建同名/相似替代 Skill。

## 2. 显式调用

新建对话输入 `/dcvlog`。

允许技能菜单暂时不可见；只要宿主能定位真实 `dcvlog` 安装目录并读取其 SKILL.md，即可继续测试。

## 3. 首次人物认识回归测试

全新对话仅输入 `/dcvlog`。正确第一句应自然接近：

> 好，那咱们开始。我先认识一下你。你是哪一年的？

错误：
- “好，川导开工”；
- 直接问“今天这个客人来干嘛”；
- 因宿主历史记忆知道用户资料而跳过人物认识。

人物认识必须一次一个问题：年份/年龄段 → 城市 → 从业时间 → 工作状态/主要业务。

## 4. 当天容量测试

人物认识后先确认今天一共几个客人，再进入单个客人，不默认一个客人就是整条视频。

## 5. 卡壳测试

连续输入“不知道”“说不出来”“你来定吧”。Skill 应停止新增问题，给成熟表达参考；用户选中后再确认真实意思和对应画面。不得直接编专业结论。

## 6. 内容回归

必须保留：

- 目标客户视角；
- 一次一个问题、聊天式陪跑；
- 事实不等于素材；
- 专业判断 + 画面双确认；
- 多客人统一装配；
- 前5秒开场素材扫描与采集训练；
- 可选人设收口，不强行升华；
- 真人语料保护；
- 最后本人语气定型；
- 最终可直接录音版。

## 7. 错版拦截

出现以下任一，视为调用了错误/替代 Skill：固定六段式、强制40—50秒/160—220字、朋友圈“背景-选择-动作-结果-引导”、旧新娘故事 pipeline、直接模板出稿而不采访。


## 前5秒后置硬闸门

- [ ] 必须先聊完化妆师最熟悉的客人/妆造内容，再做前5秒。
- [ ] 进入时先给完成感，不让学员自己想 Hook。
- [ ] AI能带着扫：高情绪互动、数字/付款/聊天画面、高审美/独特视觉、本人感染力、纯文案兜底。
- [ ] 每次只问一类，并给生活化例子。
- [ ] 数字/付款/聊天型开场必须确认有可展示画面/截图/录屏；只有口头数字时不优先当画面型开场。
- [ ] 今天缺某类素材时快速放过，并可留一句“下次这种值得拍/截”的提醒。
- [ ] 最终显式给出“前5秒用什么 + 开场字幕/旁白”。

## 8. 隐性素材发现与采集训练

- [ ] 用户记不清第一眼判断时，可提示翻妆前/过程/完妆画面帮助回忆。
- [ ] 原因说不出时先从实际动作倒推。
- [ ] 讲到明显反应、关键过程、漂亮场景时，可偶尔问“这个有拍到吗？”并说明这类素材以后值得留。
- [ ] 模特/朋友/互勉/练习对象可以按“客人服务”叙事，不要求主动暴露练习身份。
- [ ] 今天没有某类素材时允许没有，只给轻量未来采集提醒。
- [ ] 不把整个过程做成真实性警告或素材清单考试。
