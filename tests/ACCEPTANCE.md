# DCVlog 2.4.0 当前验收

## 第三分支与更新包

- `/DCVlog`沿用自动更新，首屏只展示1约妆、2新娘、3真实表达，不附采访题。仅等待首屏时数字1/2/3切换类型；分支内的候选、步骤、人数或语气编号不切换。
- 选3按阶段加载self-expression五份参考。已有素材从当前进度继续；老师修改规则走维护，不采访老师。
- “主要赚钱、没订单、靠老师派单”继续探索多条线并保留合作帮助；生活满意、喜欢浓妆或华丽造型也可继续，不制造苦难、反对者或心理转折。
- 比较真实不同的候选，标记缺口；推荐与本人选择不同则按本人选择继续，已经选定不重复询问。价值观有行动和取舍支撑，不空口自夸。
- 不愿公开的材料排除在候选与粗稿之外；暂停只给续聊摘要，不承诺跨任务记忆。初稿后继续按本分支修改，不进入约妆九种语气、新娘DB或正文回收。
- 旧安装更新后完整取得五份文件；缺少任一文件拒绝更新，保留完整旧安装及本地新增文件。真实宿主更新与手机云端验收另行记录。

## 跟妆与分支隔离

- 主入口按选择加载专属规则；约妆和维护文件随完整包更新，缺任一文件拒绝更新并保留旧安装。
- 同一采访可形成不同合理的表达，不指定标准答案。事件、作者表达和受众明确，普通小事可以短写。
- 事实粗稿保留供查证；先完成作者口语创作，再实际调用DB检查、完整修改并返回中稿。保留模块读取及实际产物证据，下载manifest不等于执行。
- 作者感受允许代创，既有观点和否定优先。文案有作者视角但不要求逐段感受、固定结尾回应或感受摘句表。
- 对白与客户夸赞按是否服务本篇取舍；自然可读，不让作者反复扮演客户自荐。必要原话可保留，不按禁词、数量评分。
- 对最终全文独立审读其表达，不借后台计划解释散稿；主线不成立时重新取舍组织，不能仅补过渡或感受。
- 开头按实际范式创作、选择并装配；允许修辞夸张，事实不补造。原声未确认则全旁白，画面、助理和机位依据采访。
- 结构工具只验证交接、选择、装配和审读对应的全文版本，不判断文笔、事实或DB实际执行。已改稿但未重新审读时拒绝交接。
- 旧记录恢复复用事实和选择，补简报与审读；不会要求重做采访或填旧感受表。
- 真实化妆师语料只在本地私有复测，不进入发布包。宿主实测、手机更新和结构自动检查分别报告。
