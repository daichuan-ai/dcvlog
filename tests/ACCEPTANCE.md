# DCVlog 2.2.0 当前验收

- 已有自动更新、1约妆/2跟妆路由、实际DB流程、原声比例与退役文件清理沿用。
- 选2实际读取故事创作指南，以事件及化妆师自己的看法、审美与理念寻找目标群体共鸣；普通小事可短写，不按题材标签或物件数量自动选最优。
- 方向能说明进入、展开与落点；同一观察可以用多个物件和动作，不能把一天库存补进薄弱切口。
- 粗稿保存并简短展示，DB创作允许重写词句、文笔、上下文、节奏与结构，不是仅润色；实际模块输入包含这些权限与原材料。
- 原始采访不改写成新造心理；创作稿可以代写讲述者当时或现在的感受，记不准一句话不自动淘汰整个方向；采访未知项通常不进入成稿。
- 单兵工作中未拍到的动作不假定为画面，观察与回忆可以旁白表达；只有大意不编成逐字原话，不把先后写成虚假因果。
- 事实粗稿后先产出作者感受方案，交真实DB完成正文，重要事实段落有作者回应，结尾在事实之外增加观点。学员没有感受语料也继续创作，不逐句要求确认。
- 正文确认及原声初选后实际执行DB独立开头优化；先形成中心判断、受众、张力、事实锚点、追看问题的简报，再实际读取范式卡，候选采用不同机制并包含开头、下一句与现有首画面，选择后装入全文并更新剪辑提示。
- 允许明显的夸张、幽默、比喻和少许超现实讲法，保持核心事件与观看兑现准确；不能因非逐字写实而削成保守摘要，也不能借夸张编新事故。
- 手机端所需新知识文件都在正式包，更新器拒绝缺失文件的包；自动检查不是模型写作质量或手机实测的证明。

- 选定后可改写接入段、删重复和调整结尾；最终全文以所选开头及下一句开篇，正文逐步兑现。
- 当前任务保存 creative-work.json，结构检查失败时按 return_to 回到对应阶段；通过只证明产物完整，实际写作判断与DB执行另验。
