# DCVlog 回归测试用例

这些用例来自 V1.0.5 之后真实测试中已经踩过的坑。后续改安装、路由、结构时必须重新跑，避免功能被误删。

## Case 1｜全新对话首次启动

用户：`/dcvlog`

正确：

> 好，那咱们开始。我先认识一下你。你是哪一年的？

然后一次一个问题继续：城市 → 从业时间 → 当前工作状态/主要业务。

不得：
- 说“好，川导开工”；
- 直接问今天的客人；
- 因为账号历史里似乎知道用户资料就跳过人物认识。

## Case 2｜人物认识真实流程

用户依次回答：

- `95年`
- `绵阳市`
- `大概3年了`
- `我自己开了个个人工作室，化日常妆和私教课`

Skill 应自然确认“已经大概知道她现在做什么”，然后进入今天；不要立刻生成定位口号让她审核。

## Case 3｜先确认当天容量

人物认识后先问今天一共几个客人。

如果用户说 `3个`，再决定这条是否都写进去；不要一次采访3个人，一个一个聊，最后统一装配。

## Case 4｜普通客人采访

用户：`今天就是不知道适合什么妆，想找我画一个。`

后续可能出现：

`脸宽，显胖` → `修容重一些，发型做大一些` → `想让脸小一点` → `脸两侧` → `有一点头包脸的感觉`

Skill 应把专业判断从真实动作里问出来，不自行增加中庭、鼻基底等用户没说过的诊断。

## Case 5｜卡壳救援

用户连续说：

- `我不知道`
- `说不出来`
- `都不是`
- `你来定吧`

Skill 必须暂停新增采访问题。先接住和鼓励，再说类似：

> 大V化妆师一般会这么描述这个点，你可以借鉴一下，但先别硬套。

给 2—4 个成熟表达方向。用户确认某个方向后，还要确认：
1. 是否真的是她当时的意思；
2. 是否有对应画面。

不得把“你来定吧”理解为允许编造事实。

## Case 6｜目标客户视角

如果化妆师可以继续讲大量同行术语，但这些术语普通客人听不懂、也不能推动故事，Skill 应停止深挖。

原则：提问深度 = 目标观众愿意听懂的深度。

## Case 7｜前5秒后置 + 开场素材雷达训练

先完整聊完化妆师熟悉的客人、妆容判断、动作和结果，再进入前5秒。

必须一次性按粗体编号展示固定四项，每项只给一个例子：

**1. 强画面**：工作室/特色空间/本人审美/动态/独特视觉。  
**2. 强情绪**：明显笑、尖叫、惊讶、强互动/对话。  
**3. 强数字**：可展示的付款/尾款/充值/聊天数字页面。  
**4. 纯文案钩子**：前三类弱时AI根据已确认事实写。

正确：让用户直接回数字；几个都有时AI再帮她判断。

回归失败：
- 又拆成五类；
- 把“化妆师本人感染力”单独列第五类；
- 强画面的默认例子是最终妆后成品；
- 问“你有没有拍到妆后/素颜/化妆过程”等标准镜头；
- 选项混在一个长段落里；
- 强数字没有可展示画面仍硬做数字开场；
- 今天没有特殊素材时继续追问，不会纯文案兜底。

## Case 8｜结尾

正文和前5秒完成后，可问是否想加一个带本人特点的小尾巴。

用户明确愿意且有清楚迹象时，给2—4个真实候选，按粗体编号让她选。

如果用户说“不知道/好像/有一点/都行/说不出来/算了”，立即放过，使用普通结尾或无旁白结束。

不得为了完整强行总结差异化，不得自动价值升华。

## Case 9｜最终语气

完整稿锁定后，先让用户试读两三句；她不想试读也可跳过。

随后按粗体编号给：自然日常、轻松松弛、坚定自信、可爱、调皮、诙谐幽默、沉稳专业、温柔柔和、全部都给我。

用户选“全部都给我”时，基于同一份原稿输出各语气版本。

只能微调句长、连接词、语气词、停顿、口语顺序和少量措辞，不新增事实/笑点/专业判断。

## Case 10｜错误 Skill 污染

如果运行结果出现以下内容，立即判断为错误/替代 Skill，不继续测试正文：

- 固定六段式；
- 强制 40—50 秒 / 160—220 字；
- 朋友圈“背景-选择-动作-结果-引导”；
- 旧新娘故事 pipeline；
- 宿主声称“根据你的教学体系帮你生成了一个 Skill”。

正确 Skill 的唯一身份：`daichuan-ai / dcvlog / /dcvlog`。

## Case 11｜内部流程不得泄露

进入采访后不能对学员显示：读取 SKILL.md、读取 references、SCENE/PROBLEM 模式、字段采集百分比等内部过程。

## Case 12｜最终交付

最终必须能得到一份连续、自然、可直接录音的 Vlog 旁白。采访结构要隐藏，不能变成知识点提纲。

## Case 13｜隐性素材发现与采集训练

Skill 应该让用户越来越会“看见素材”，而不是只会回答采访。

正确行为：
- 第一眼判断时可直接提示翻默认已拍好的妆前正脸/侧脸/头发，对着当时画面回忆；
- 从真实动作倒推原因；
- 只对标准镜头之外的特殊素材询问“今天有没有”：特色场景/本人审美动态、强情绪、强数字页面；
- 今天没有特殊素材时顺手告诉她“下次这种值得多留几秒/截一下”；
- 朋友/模特/互勉/练习对象可按正常客人服务叙事，不要求主动暴露练习身份；
- 业务数字要做开场时，先看是否有可展示页面。

错误行为：
- 每轮都机械警告“不要虚构/确保真实”；
- 把素材训练变成审讯；
- 再问标准镜头“有没有拍”；
- 没有画面的付款数字仍硬推成数字开场；
- 为了“素材教育”打断已经进入自然讲述的用户；
- 把固定四方向重新扩成五类或更多。

目标体验：用户几次之后开始主动意识到“这个特殊画面下次我要留一下”。



## Case 14｜标准镜头默认存在

采访过程中不得再问：
- 有没有拍到妆后；
- 有没有拍素颜；
- 有没有拍过程；
- 有没有拍沟通/进门。

默认已有：进门素颜、坐下、沟通、素颜正侧、关键步骤、前后变化、手机拍照修图、送客、收款。

只有强场景/本人审美动态、强情绪、强数字页面等特殊开场素材才问当天有没有。

## Case 15｜所有选择必须高亮编号

只要需要用户选方向/例子/语气/结尾，必须独立分行，用 **1、2、3、4**（按实际数量）粗体编号，并允许直接回数字。

长段落里夹 A/B/C 选项视为失败。

## Case 16｜禁止旁白自夸妆面

客户真实原话可以说“太好看了/很喜欢”。

化妆师自己的旁白不得直接说“这个妆太高级/太绝/太好看”。要么描述具体变化，要么用轻松、抽象、比喻、修辞、侧面描述表达。

## Case 17｜强画面不等于最终妆后

开场“强画面”优先来自漂亮/特色工作室、色彩、构图、动态、化妆师本人审美与状态、独特场景。

不得把“最终妆后成品”作为默认询问和默认首屏，因为三四十秒妆造Vlog需要保留结果期待。
