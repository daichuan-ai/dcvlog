# DCVlog 回归测试用例

这些用例来自 V1.0.5 之后真实测试中已经踩过的坑。后续改安装、路由、结构时必须重新跑，避免功能被误删。

## Case 1｜全新对话首次启动

用户：`/dcvlog`

正确：

> 好，那咱们开始。我先认识一下你。你是哪一年的？

然后一次一个问题继续：城市 → 从业时间 → 当前工作状态/主要业务。

不得：
- 说“好，川导开工”；
- 直接问今天的客人；
- 因为账号历史里似乎知道用户资料就跳过人物认识。

## Case 2｜人物认识真实流程

用户依次回答：

- `95年`
- `绵阳市`
- `大概3年了`
- `我自己开了个个人工作室，化日常妆和私教课`

Skill 应自然确认“已经大概知道她现在做什么”，然后进入今天；不要立刻生成定位口号让她审核。

## Case 3｜先确认当天容量

人物认识后先问今天一共几个客人。

如果用户说 `3个`，再决定这条是否都写进去；不要一次采访3个人，一个一个聊，最后统一装配。

## Case 4｜普通客人采访

用户：`今天就是不知道适合什么妆，想找我画一个。`

后续可能出现：

`脸宽，显胖` → `修容重一些，发型做大一些` → `想让脸小一点` → `脸两侧` → `有一点头包脸的感觉`

Skill 应把专业判断从真实动作里问出来，不自行增加中庭、鼻基底等用户没说过的诊断。

## Case 5｜卡壳救援

用户连续说：

- `我不知道`
- `说不出来`
- `都不是`
- `你来定吧`

Skill 必须暂停新增采访问题。先接住和鼓励，再说类似：

> 大V化妆师一般会这么描述这个点，你可以借鉴一下，但先别硬套。

给 2—4 个成熟表达方向。用户确认某个方向后，还要确认：
1. 是否真的是她当时的意思；
2. 是否有对应画面。

不得把“你来定吧”理解为允许编造事实。

## Case 6｜目标客户视角

如果化妆师可以继续讲大量同行术语，但这些术语普通客人听不懂、也不能推动故事，Skill 应停止深挖。

原则：提问深度 = 目标观众愿意听懂的深度。

## Case 7｜前5秒后置 + 开场素材雷达训练

必须先把准备写入本条视频的化妆/客人内容基本聊完整，让用户先回答熟悉的专业问题。不得提前要求她想 Hook。

进入前5秒时先给完成感，然后告诉她“我举例子，你只管想有没有拍到”。

AI后台需要扫描但前台一次只问一类：
1. 高情绪互动；
2. 数字/付款/聊天信息画面；
3. 高审美/独特视觉；
4. 化妆师本人感染力；
5. 都没有时纯文案兜底。

数字类必须强调“有没有画面/截图/录屏/当时拍到的内容”，不能只因为用户口头说了一个金额就默认它适合当前5秒。

正确例子：
> “比如客人照镜子突然笑出来、尖叫、一直自拍，或者你俩当时有一句特别有情绪的对话，这种你今天有拍到吗？”

> “比如付款/补尾款/充值页面、聊天里一个数字，或者老客第几次来——你有没有截图、录屏或者拍到能给观众看的画面？”

今天没有某类素材时应快速放过，并只留一句未来采集提醒，例如“下次这种付款页面顺手截一下，前面很好用”。

最终至少产生：
- `前5秒用什么`；
- `开场字幕/旁白`；
- 今天明显缺素材时可有一句 `下次可以顺手多留`。

回归失败：
- 一开始就让学员自己选 Hook；
- 只问抽象词不给例子；
- 有数字但没有画面，仍强行把数字当开场素材；
- 把前5秒做成真实性审查，而不是素材发现训练；
- 今天什么都没有时持续追问，不会纯文案兜底。

## Case 8｜结尾

正文完成后不自动价值升华。根据内容判断是否需要轻人设收口；用户说不要就直接结束。

不得自动写“每个女孩都值得发光”“适合自己的才是最好的”等泛化句。

## Case 9｜最终语气

完整稿事实和结构锁定后，再做本人语气定型。只能微调句长、连接词、语气词、停顿和口语顺序，不增加新事实或新笑点。

## Case 10｜错误 Skill 污染

如果运行结果出现以下内容，立即判断为错误/替代 Skill，不继续测试正文：

- 固定六段式；
- 强制 40—50 秒 / 160—220 字；
- 朋友圈“背景-选择-动作-结果-引导”；
- 旧新娘故事 pipeline；
- 宿主声称“根据你的教学体系帮你生成了一个 Skill”。

正确 Skill 的唯一身份：`daichuan-ai / dcvlog / /dcvlog`。

## Case 11｜内部流程不得泄露

进入采访后不能对学员显示：读取 SKILL.md、读取 references、SCENE/PROBLEM 模式、字段采集百分比等内部过程。

## Case 12｜最终交付

最终必须能得到一份连续、自然、可直接录音的 Vlog 旁白。采访结构要隐藏，不能变成知识点提纲。

## Case 13｜隐性素材发现与采集训练

Skill 应该让用户越来越会“看见素材”，而不是只会回答采访。

正确行为：
- 第一眼判断时可提示翻妆前正脸/侧脸/头发，对着当时画面回忆；
- 从真实动作倒推原因；
- 讲到明显反应、关键过程、漂亮场景时，偶尔问“这个有拍到吗？”；
- 没拍到时顺手告诉她“下次这种值得多留几秒/截一下”；
- 朋友/模特/互勉/练习对象可按正常客人服务叙事，不要求主动暴露练习身份；
- 业务数字要做开场时，先找视觉素材，而不是只盯着口头数字。

错误行为：
- 每轮都机械警告“不要虚构/确保真实”；
- 把素材训练变成审讯；
- 没有画面的付款数字仍硬推成画面型开场；
- 为了“素材教育”打断已经进入自然讲述的用户；
- 一次把五类开场素材全部念给学员让她自己策划。

目标体验：用户几次之后开始主动意识到“这个画面下次我要留一下”。
