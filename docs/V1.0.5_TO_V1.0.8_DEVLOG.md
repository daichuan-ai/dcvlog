# V1.0.5 → V1.0.8 开发记录

这份文件记录从 V1.0.5 之后真实实机测试得到的结论。目的不是给普通学员看，而是避免后续开发重复走弯路。

## V1.0.5：核心内容逻辑定型

V1.0.5 已经把产品真正有价值的内容层确定下来，后续版本原则上不随意重写：

- 采访式创作：先聊事实，不先写稿；
- AI 先进入目标客户视角，再采访化妆师；
- 一次只问一个现实问题；
- 用户卡壳时进入救援，不连续逼问；
- AI 给出的专业表达必须同时确认“本人真实判断”和“现场有画面可支撑”；
- 多客人先分别采访，再统一装配；
- 前 5 秒单独做真实素材选择；
- 正文结束后可做轻人设收口，但不强行升华；
- 最后只做本人语气微调；
- 优先保护真人语料，不把所有话统一改成标准 AI 文案。

## V1.0.6：曾尝试用独特暗号解决路由

当时把自然语言启动词改成更独特的“代川妆造Vlog编导开工”，并设置“川导开工”回执。

实测结论：**如果 Skill 根本没有被宿主发现或加载，暗号写得再独特也没有意义。** 安装/发现问题发生在 Skill 正文执行之前。

## WorkBuddy 实测：云端与本地不是同一个运行环境

测试中出现过：某个云端任务里显示 Skill 已经下载和校验成功，但新建云端任务后并没有稳定发现它。

同时，手机远程控制电脑与手机纯云端任务不是同一环境。电脑本地安装的 Skill，在电脑关闭、手机切到纯云端时，不能简单假定仍然存在。

因此以后必须区分：

1. 本地电脑 Skill；
2. 当前云端沙箱 Skill；
3. 宿主真正注册/可发现的持久 Skill。

“文件下载成功”不等于“技能列表已经发现”。

## V1.0.7：引入 `/dcvlog`，但身份仍未完全统一

V1.0.7 把 Skill 内部名改成 `dcvlog`，增加 `/dcvlog` 手动入口，避免只依赖自动路由。

但当时仍存在身份分裂：

- GitHub 仓库：`daichuan-ai/dc-makeup-vlog`
- Skill name：`dcvlog`
- 中文显示名：代川｜妆造Vlog编导
- 自然语言安装词又有多个版本

对人类来说这些都指向同一个产品，但安装 Agent 在 Skill 尚未下载前只能依赖公开身份进行定位，身份越多越容易猜错。

## 豆包工作实测：最关键的新发现

一次安装失败后，豆包工作没有安装 GitHub 上的真实 Skill，而是根据用户职业和历史聊天，**自行生成了一个新的相似 Skill**。

这个替代 Skill 随后真的出现在技能列表里，导致新聊天点击后看起来像“已经安装成功”，实际运行的是错误内容，例如旧的六段式结构、40—50 秒、朋友圈框架等，与 V1.0.5 之后的真实 DCVlog 逻辑无关。

由此确认：

- GitHub 真实 Skill 当时其实没有进入技能列表；
- 测试环境曾被宿主自动生成的假 Skill 污染；
- 不能再用“它说安装完成了”作为成功标准；
- 必须核对来源、`name`、`author`、`version`，并从技能列表实际调用后再验收；
- 安装之前宿主还看不到 `SKILL.md` 正文，所以**不能指望在 Skill 正文里解决仓库定位错误**。

## V1.0.8：发行身份彻底统一

V1.0.8 不改 V1.0.5 的核心采访与成稿能力，只修改安装与发现层。

统一成唯一身份：

- GitHub owner：`daichuan-ai`
- GitHub repo：`dcvlog`
- GitHub coordinate：`daichuan-ai/dcvlog`
- Skill name：`dcvlog`
- Slash：`/dcvlog`
- 显示名：`代川 DCVlog｜化妆师Vlog编导`
- 学员安装口令：`安装代川的 dcvlog`
- 更明确的安装口令：`安装 daichuan-ai 的 dcvlog`

这样安装 Agent 不需要把“dc-makeup-vlog、DCVlog、妆造Vlog编导、代川编导”几个不同名字推理成同一产品。

## 当前验收原则

一次真实安装必须同时满足：

1. 来源确认为 `https://github.com/daichuan-ai/dcvlog`；
2. `name=dcvlog`；
3. `author=daichuan-ai`；
4. `version=1.0.8`；
5. 重启宿主后，技能列表真实出现 **代川 DCVlog｜化妆师Vlog编导**；
6. 从技能列表或 `/dcvlog` 调用后，第一句进入“川导开工”采访逻辑；
7. 不出现旧六段式、固定 40—50 秒、朋友圈框架、新娘故事旧流程等不属于本 Skill 的内容。

只有七项同时满足，才算“安装成功”。
